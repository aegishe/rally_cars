# ADR-0001：属性权衡的代价审计——项目全局分析第一原则

> **Status: Accepted（2026-09-03）**
> **范围：全部体系**（越野 offroad / 赛道 track / 派克峰 pikes-peak / 家用 daily-touring / 完美电驱 perfect-e-offroad）——任何分析车辆参数的文章与打分都适用。

## Context（为什么立这条）

- 车辆是**多轴系统**（动力 / 热 / 质量 / 控制 / 几何至少五根轴同时工作），任何账面优势的代价不会消失，只会**转移到未被优化的那根轴**——单轴账面 ≠ 真实账。
- 营销语言天然只报单轴账面（这是项目"参数祛魅"写作主题的根源）；参数表里"少掉的东西"一定以别的字段长回来（门桥用重量换离地、后置布局用空间换配重、电池用体积换能量）。
- 触发素材链（2026-09-03 一批视频素材集中暴露四类隐藏代价）：Crusty 载荷转移 / Sendycar TC 点火削减 / Dr.Kev 水电容效应 / Mason 门桥质量交易 / U9X 兑现率 / 尼三锅悬架对照 / G700 峰值 vs 持续。

## Decision（确立什么）

1. **命题**：整车任何账面优势的**代价不可消除、只可转移或隐藏**——表述借用复杂度守恒定律（Tesler's Law：系统复杂度 "cannot be removed or hidden, only shifted"），把"复杂度"推广为"一切工程代价"。
2. **四类代价载体**（隐藏代价优先检查清单）：
   - **热**：一切低效（NA 高海拔掉功率、TC 点火削减、变速箱损耗、持续高负荷）的最终汇点——由散热系统统一结算，故散热问题往往是别处低效的"显影液"。
   - **质量**：重量本身 + 复利（质量驱动结构加强 → 更重）；簧下质量、电池、门桥减速器皆属此类。
   - **复杂度**：系统复杂度守恒，只转移不消失——机械件复杂度换电控省心、反之亦然；复杂度还以"故障概率/维护成本"形式付利息。
   - **控制保守**：ECU/TC/扭矩管理软件策略的隐性折扣——账面与轮上全对，但赛道兑现被"没敢给"或"被掐掉"的部分，纯电/混动尤其严重（软件定义动力）。
3. **审计两步法**（分析任何车/架构/成绩时）：
   - ① 对每个账面优势/宣传参数问三问：**代价付在哪根轴？以什么形式？何时兑现（即时 / 延迟）？**
   - ② 把散落各轴的代价**显式化后跨系统加总**，才是真实账。

## Rationale（为什么对）

- 与项目既有原则的关系：**兑现率**（track）、**口径纪律**（持续 vs 额定 vs 峰值）、**SOC 三状态**、**场景打分标准**、**散热守恒**观察——全是本原则在特定体系的特例/实践。收拢为一条显式原则后，各体系可回链。
- "被隐藏的代价"正是"车辆是系统工程"的必然推论：子系统局部最优 ≠ 全局最优，代价守恒保证任何单轴优化必有他轴偿还。

## Consequences

- **正面**：分析清单化（四类载体 + 两步法）；可直接反制单轴宣传口径；为"参数祛魅"主题提供底层论证。
- **边界（勿滥用）**：审计不是否定账面——单轴账面仍有营销层/初筛价值；只对**关键参数**做深审计，避免无限展开（每个数字都追四类代价会瘫痪行文）。
- **风险与纪律**：跨系统加总需要口径统一——引用必标"代价口径"（如持续 vs 峰值、是否含热降级、控制策略是否介入）；区分"设计取舍"（有意的 trade-off）与"缺陷"（无意的低效），二者审计结论不同。

## Evidence（素材证据链，均为已归档信源）

| 案例 | 账面 | 隐藏/转移的代价 | 信源 |
|---|---|---|---|
| 载荷转移 | 高滚动中心 → 车身不侧倾 | jacking force、shock load 轮胎、总抓地"被借走"损失 | 清单越野 #18（Crusty） |
| TC 点火削减 | 700whp 账面+轮上 | 赛道兑现被 ECU 掐掉（~1s/min 隐性）；错误以**热**形式存储、几分钟后水温爆表 | 清单派克峰 #1（Sendycar） |
| 散热按平均标定 | 街车散热体积小/重量轻 | 进持续高负荷场景（赛道/环塔）必过热——热账按平均算就会在峰值时段爆 | 清单赛道 #10（Dr.Kev） |
| 门桥 | 离地间隙 / 行程解放 | 每侧簧下质量 +、多级传动效率 -3-5%、复杂度/成本 | 清单越野 #17/#19（Mason/Animagraffs） |
| U9X vs SU7 | 2220kW 账面 | 兑现 73-79%：重量 2480kg + 控制保守（出弯 30-40% 油门） | track 篇2/2s |
| 悬架形式对照 | 整体桥皮实成本低 | 沙坡/高速场景抓地与稳定性代价（登顶名单全独立悬架） | 清单越野 #16 |
| G700 峰值功率 | 账面 665kW | 环塔 SS9 蠕行 50-60kW（P1 持续仅 60kW）——"峰值是短视频货币、持续是比赛货币" | CONTEXT-MAP 越野定论 |

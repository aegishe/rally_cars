# 第一部分 · 现状与定位

## 1.1 这个项目现在是什么

原目标：从 CLTC 官方指标反推纯电车的真实电耗与效率，进而算冬夏 × 载重 × 长短途的续航矩阵。

**当前正确定位**：Stage-1 应当是**欠定审计**，而不是"效率反推"。
原因：CLTC 官方只给 1 个电耗观测，而每车有 5 个未知量（见 §1.3）。

## 2.4 三条硬结论（可直接对外使用）

**① CLTC-P 特征表闭合，拥堵集中在一部**：1部怠速占比 **35.16%**（总体仅 22.11%）

**② 分段阻力功率与"隐含高速税"**（纯物理，零标定，Model 3）：

| 段 | 运行车速 | 阻力功率 | 时间占比 | 里程占比 | **阻力功占比** |
|---|---|---|---|---|---|
| 1部 | 20.20 | 0.923 kW | 37.4% | 16.9% | 18.1% |
| 2部 | 38.24 | 2.000 kW | 38.5% | 40.8% | 40.3% |
| 3部 | 53.89 | **3.305 kW** | **24.1%** | **42.3%** | **41.6%** |

> **高速段仅占 24.1% 时间，却贡献 42.3% 里程、41.6% 阻力功。**
> "总体平均车速 28.96" 这一个数字把该结构完全掩盖 → 这就是 CLTC 电耗看起来总偏低的机制。

**③ 附件税 = 100/v（kWh/100km per kW）**（纯数学，无参数自由度）：

| 车速 | 每 1kW 附件的电耗 |
|---|---|
| 20 km/h | **5.00** |
| 30 km/h | 3.33 |
| 60 km/h | 1.67 |
| 80 km/h | 1.25 |
| 120 km/h | 0.83 |

低速工况附件每公里代价是高速的 **6 倍**。

# 第三部分 · 禁区（本次踩过的坑，重复即浪费）

## 3.1 数据提取类

| # | 禁令 | 实测证据 |
|---|---|---|
| D1 | **不可用 pypdf 解析表 A.1** | 文本层数字无分隔符，`1114.7` = t=11,v=14.7，歧义组合爆炸。DFS 超时，7 种策略全卡在 t≈35 |
| D2 | **不可用图像数字化读曲线** | 与用户提供的 4 个锚点平均误差 **53.6 km/h**，且加减速方向读反（把加速段读成下降）。曲线图精度不足以支撑动能积分 |
| D3 | **正确方法：PyMuPDF + 词坐标聚类** | PyMuPDF 保留数字分隔；按 x 坐标分列块可 100% 还原 |

## 3.2 建模类（更严重）

| # | 禁令 | 踩坑记录 |
|---|---|---|
| M1 | **余项不得命名成物理量** | `官方电耗 − 阻力 − 低压 = 1.165 kW` 被我命名为"净动能项"，据此反解 φ，得 **φ=−5.19**（非物理）。它里面装着电驱损耗+动能损失+未建模项，**必须标注"（余项）"且不得用于反解** |
| M2 | **恒等式不得作为指标** | "综合效率"= (阻力+净动能)/电池输出 ≡ (电池输出−低压)/电池输出 ≡ 1−低压占比，**只反映低压占比，零车型信息**。此类指标应删除而非修正 |
| M3 | **单位链必须自检** | 三次错误：`power/v×100` 漏除 1000（差 1000 倍）、表格列解析串位、`×3.6` 与 `÷3.6` 反向 |
| M4 | **不得用"事件数 N"做自由度** | CLTC"加速比例"指**秒数占比**，`ΣΔv = a_acc·t_acc` 即逐秒增量之和，无需事件数 |
| M5 | **逐秒增量求和后不得再平方** | `(ΣΔv)²/2` 等于把 518 个加速秒当成一次连续加速 → 得 9.98 kW（官方总功率才 2.74 kW） |
| M6 | **统计量无法还原分布** | 均值不决定平方和。特征表给的是统计量，动能积分 `Σ½Δv_i²` 需要逐秒分布 |
| M7 | **建模前先做欠定审计** | 列"观测数 vs 未知数"，不足就明说，不要硬出结论 |

## 3.3 已知的口径陷阱

| 陷阱 | 说明 |
|---|---|
| CLTC 试验质量 | = 整备 + 最大装载×65%，**不是整备、不是满载** |
| "平均加速度 0.45" | 是**加速事件内部**统计；逐秒积分 ΣΔv=74.7 m/s，而 0.45×518=233 m/s，**差 3 倍** |
| 实测达成率 | 受测试路线主导，不能反推申报口径（YU7 北京五环实测 93.9~97.4%） |
| 官方 Cd | 对应特定轮毂，量产车实际值可能更高 |

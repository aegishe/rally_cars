# 城际巡航 — 按价格段对比

> 场景定义：省际高速/好国道，核心问题是"能不能舒服地到达"。和规格对决不同——城际巡航不关心 0-100 和极速，关心的是**高速续航、补能速度、长途舒适、智驾省力**。
>
> 三档距离：
> - **省内跨市**（200-400km）：任何纯电一趟到，纯电体验最优
> - **邻省中距**（400-600km）：续航 700+ 纯电可一趟，续航 500- 需充电一次——临界区
> - **省际长距**（600-1000km）：所有纯电必须中途补能，补能速度决定体验

---

## 10-20 万：混动几乎碾压

**一句话结论：这个价格段纯电续航多在 500-600km，邻省中距就开始焦虑。秦L DM-i 的 2000km+ 综合续航是降维打击。**

## 30-40 万：舒适和智驾决胜负

**一句话结论：续航和补能在这个价格段已不是瓶颈。真正的差异在"坐得舒不舒服"和"开得累不累"。问界M7的华为ADS和理想L7的魔毯舒适，是两个不可兼得的巅峰。**

**一句话结论：这个价格段不存在"选谁"的问题——增程/换电已经解决了城际巡航的所有焦虑。真正的问题是"你要多大尺寸"。**

- 🥇 要轿车 → **56E 随便选**（智驾落后，但"开到任何酒店门口都不丢人"的信仰无价）

- 🥇 硬派长途 → **坦克700 Hi4-T**（V6+P2零焦虑，但如果你只是跑高速买它亏了）

## 跨价格段总结：城际巡航的核心定律

| 距离 | 最优方案 |
|---|---|
| **省内跨市**（200-400km） | 纯电最佳——零延迟+安静+智驾。任何 500km+ 续航纯电一趟到。 |
| **邻省中距**（400-600km） | 续航 700+ 纯电（SU7）可一趟；续航 500- 的需充电一次。**增程/插混的"加油就走"在 500km 以上开始显现价值。** |
| **省际长距**（600-1000km） | 混动/增程/燃油零焦虑优势最大。纯电需 1-2 次充电，**补能速度（800V/换电）比续航厚度更重要。** |
| **所有距离** | **高速 NOA 是城际巡航的隐藏核心维度。** 智驾好的车，400km 的实际疲劳感约等于没有智驾的 200km。 |

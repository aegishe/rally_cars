# 硬派SUV组 — 规格对决

> 场景定义：纯账面指标对比，KOL/网友虚空对战。
> 
> 硬派SUV的定义：非承载式底盘（或等效强度），真正的越野底子。和风味越野（承载式方盒子）的本质区别在于底盘结构。
>
> 关键架构区分：
> - **T系（Hi4-T）**：3.0T V6 或 2.0T + P2 单电机并联 → **有机械直驱，亏电不掉底**
> - **Z系（Hi4-Z）**：2.0T + 动力分流 + 解耦四驱 → **电驱为主，纯电续航更长，但亏电后无机械直驱**
> - **DMO（豹系）**：单档混动 P1+P3+P4 → **电驱硬派，攀爬甜点，亏电后全线依赖 P1 发电**
> ⚠️ **比亚迪系（含方程豹/仰望）**：全系有频繁官降传统，"背刺车主"影响高端化。
> 📝 **宣传名词速查**：云辇/云辇-P=智能车身控制 | 天神之眼=比亚迪智驾 | 易四方=四轮独立电机 | DM-o=单档混动越野平台 | Hi4-T=长城P2混动 | Hi4-Z=长城解耦四驱 | 途灵底盘=华为智能底盘 | 乾坤/ADS=华为智驾

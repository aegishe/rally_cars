## 一、Wikipedia 车身形式主干

Sedan（三厢）/ Hatchback（两厢）/ Station wagon（旅行车）/ Coupé（轿跑）/ Convertible-Roadster（敞篷）/ Shooting brake（猎装）/ SUV / Crossover（跨界）/ MPV-Minivan / Pickup（皮卡）/ Van（厢式）

## 二、切法对照：用途 vs 形式（正交）

篇6 矩阵按「用途 / 载什么」切（小体量·灵活 / 驾驶者 / 人 / 人+货 / 货），Wikipedia 按「车身形式」切（几厢 / 几门 / 顶棚）。两者正交，用途切法更适合选车（读者问"载几个人几箱货"，不问"几厢"）。

## 四、遗漏检查

- 敞篷（Convertible / Roadster）：驾驶者列的一种顶棚形态（双门轿跑常有两门敞篷版），中国极小众，不单列——与旅行车同样处理（提一句即可）。
- 其余车身形式已被矩阵覆盖（用「用途」重新组织，非按「形式」）。

## 五、命名规范化建议

矩阵正文用中文通用俗称；如需对外口径对齐，可标注 Wikipedia 术语（如"两厢＝Hatchback""MPV＝Minivan""厢货＝Panel van"）。中文俗称中「微面 / 微卡 / 厢货」三者边界需按座位数钉死：微面＝5-7 座载人载货、微卡＝2 座小货斗、厢货＝2 座封闭货厢。

# 长途穿越 — 非铺装场景硬派SUV对比

> 场景定义：非铺装为主，带越野属性的旅游，**轿车走不了**。典型路线：丙察察、阿里中线、大海道。上限是**弃车人走**——不需要防滚架和赛事级散热防护，但需要车辆在持续非铺装路面不掉链子。
>
> 本场景**仅硬派SUV组参与**。城市SUV和风味越野（承载式底盘）在持续非铺装路面上底盘刚性不足——一趟丙察察下来可能异响不断。
>
> 核心维度：**亏电后体验衰减（最核心）、续航厚度（非铺装油耗暴增）、悬架和地形模式、舒适性（持续颠簸）**
>
> 物理基础（来自越野体系+环塔实战）：
> - **亏电后可持续功率不由满态峰值决定，由"亏电后还有多少机械直驱功率"决定**
> - **P2并联（油主电辅）+机械四驱 = 当前长途非铺装最优解**（环塔验证）
> - **电驱越野存在保电瓶颈：>350km 纯沙漠断崖掉速**（家用长途穿越不一定这么极端，但规律相同）
> - **增程式在持续非铺装被双向夹击：小排量发动机发电不够+电驱散热不足**

## 架构速查：长途穿越的生死线

| 架构 | 亏电后 | 长途穿越适用性 |
|---|---|---|
| **P2 并联 + 3.0T V6**（坦克700 Hi4-T） | 3.0T V6 直驱 ≈ 260kW，**不掉底** | 🟢 **最优解** |
| **P2 并联 + 2.0T**（坦克500 Hi4-T） | 2.0T 直驱 ≈ 180kW，**不掉底** | 🟢 **次优** |
| **P2 并联 + 2.0T**（坦克300 Hi4-T） | 2.0T 直驱 ≈ 180kW，**不掉底** | 🟢 **次优** |
| **燃油 V6**（坦克500 3.0T） | 永远 190kW | 🟢 可靠但油耗高 |
| **燃油 2.0T**（坦克300） | 永远 162kW | 🟡 够用但油耗高 |
| **解耦电四驱 Hi4-Z**（坦克300/500/700 Z） | 2.0T 发电→电驱，**无机械直驱** | 🟡 亏电后体验降档 |
| **DMO 单档混动**（豹5） | P1 发电→电驱 ≈ 91kW（环塔实测），**断崖掉速** | 🔴 短途可以，长距危险 |
| **增程式**（仰望U8易四方） | 2.0T 发电→电驱，喂不饱四电机 | 🔴 同上 |
| **纯电** | 不存在（非铺装没有充电桩） | ⚫ 不可行 |

> ⚠️ 家用长途穿越的上限是"弃车人走"——但谁也不希望真的弃车。**亏电不掉底 = 能自己开回去。亏电断崖掉速 = 可能需要救援。**
> 
> ⚠️ **悬架的终极选择**：云辇（液压）、空悬、6D液压互联——这些在铺装路面和轻度越野中是神器。但真正极限越野（环塔/达喀尔级别），唯一可靠的是**金属弹簧+氮气减震**。液压/气压系统在持续高强度冲击下有泄漏和失效风险。卫士OCTA达喀尔赛车用的也是纯机械限滑差速器，不是民用的6D液压互联。豹5的云辇-P在城市和攀爬场景是优势，但放到需要"开回来"的长途穿越中，可靠性不如坦克系的传统弹簧+氮减方案。

## 终极结论：长途穿越的物理定律

| 定律 | 内容 |
|---|---|
| **第一定律** | 亏电后还能输出多少**机械直驱功率**，决定了你能开多远。P2 ≈ 180-260kW（排量决定），DMO 豹5 ≈ 91kW（环塔实测）。差距不是 30%，是 **"能开回去" vs "叫救援"**。 |
| **第二定律** | 机械锁不会发热、不会亏电、不会软件崩溃。电子限滑在攀爬间歇是好用，在持续非铺装是隐患。 |
| **第三定律** | 油箱越大越安心。非铺装油耗比高速高 50-100%，80L 油箱可能只够跑 500km。 |
| **第四定律** | 前后双叉臂独立悬架在持续颠簸路面比后整体桥舒适 2 倍以上。但后整体桥**不会坏**。 |
| **核心矛盾** | **P2 并联 = 可靠但油耗高。DMO = 满电猛但亏电危。纯电/增程 = 不适合这个场景。** |

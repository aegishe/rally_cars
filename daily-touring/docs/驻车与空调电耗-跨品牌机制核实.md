# 驻车电耗与空调电耗：两个网络论调的跨品牌核实

> 日期：2026-09-21 ｜ 触发：海豹08 电耗分析引出用户假设——「① 车机/相关硬件设计导致哨兵电耗高；② 冷却系统设计导致空调能耗高」→ 核实"网上有没有这种论调、站不站得住"

## 0. 一句话结论

**论调①（哨兵电耗由电子电气架构决定）成立，且已是业界共识——小米、理想都在用"架构"公开解释自家哨兵为何省电，比亚迪被指架构代际落后。
论调②（冷却系统设计导致空调费电）存在但归因错误——比亚迪热管理（宽温域热泵 + 冷媒直冷直热）在公开评价里是强项，不是短板。**

---

## 1. 论调① 哨兵电耗 ← 电子电气架构：**成立**

### 1.1 机制（业界通用的解释框架）

哨兵模式不是"一个摄像头待机"，而是**整车一整套域控制器 + 环视摄像头 + 超声波雷达持续低功耗运行**：

> "哨兵模式等于是控制器一整套包括周视摄像头和周身超声波雷达都在低功耗运行，不像门锁只运行个单片机摄像头，所以功耗比较大。" — NGA tid=45107661（2025-09-14，**正文抓取失败，仅搜索摘要**）

因此**功耗由电子电气架构决定**：域控制器数量、通讯链路长度、主控芯片待机功耗、以及"能否切低压蓄电池供电"。

### 1.2 厂商侧的官方论证（这条论调最硬的部分）

| 主体 | 官方/媒体口径 | 关键数字 |
|---|---|---|
| **小米** | EEA 页把"哨兵模式 → 通讯链路精简"列为架构收益；YU7 采用**四合一域控**（辅助驾驶域+座舱域+通讯域+整车域） | **功耗降低 40%**（小米汽车实验室） |
| **小米新一代 SU7** | "电子电器架构全面升级 → 该功能电耗直接降低 40% 以上" | **整晚仅 1 度多电** |
| **新一代车型通用方案** | "首先从**算力芯片**下手，降低主控芯片待机功耗" | 守护模式耗电降低约 40% |
| **理想**（官方产品经理文） | "允许哨兵模式优先使用**蓄电池**供电，此时**动力电池不参与**" | "能耗比动力电池供电时低得多" |
| **特斯拉** | 2024.38.4 OTA 专门做哨兵功耗优化 | "若每辆车的耗电减少约 40%" |

**含义**：比亚迪被点名"还在用几年前的哨兵逻辑"（NGA tid=47501750，145 楼 uid=63691574），且其供电策略未采用"蓄电池优先"方案——**这是架构层面的差距，不是"用户不会用"。**

### 1.3 判定

**成立。** 而且它同时解释了两件事：
- 为什么**比亚迪不同车型的哨兵功耗差异极大**（4-10 度/天）——架构代际差
- 为什么**海豹08 这种高配车更差**——车上待机的域控制器与感知硬件更多

## 2. 论调② 空调电耗 ← 冷却系统设计：**论调存在，但归因相反**

### 2.1 比亚迪热管理在公开评价中是**强项**

- e平台3.0 **宽温域热泵 + 六通阀**，2021 年**全面取消 PTC**（PTC 是电车冬季耗电元凶，制热 COP < 1；热泵 COP 1.5-5）
- **电池冷媒直冷直热**：砍掉冷却液中间环节，减少一次换热热阻；取消水泵、副水箱、水冷板等部件
- 与电驱余热耦合，冬季回收电驱废热供暖

这些是**被行业分析普遍正面评价**的技术路线，不是缺陷。

### 2.2 真正存在的批评只有两条，且都不是"空调费电"

| 批评 | 证据 | 说明 |
|---|---|---|
| **直冷均温性（第一代）** | 比亚迪官方称第二代直冷"通过优化流道，**均温性能提升 45%**" | **反推**：不解决就不需要提升 45%——第一代均温性确有短板 |
| **低温加热依赖脉冲自加热** | 直冷"无法在零下低温条件下给电池加热"（技术文口径） | 比亚迪用**电池智能脉冲自加热**（内阻产热）补此短板，属方案选择非缺陷 |
| **冷却系统热阻质疑** | [r/electricvehicles](https://www.reddit.com/r/electricvehicles/comments/1ivlvrt/byd_tang_111_kwh_failed_1000_km_challenge/)："要么是冷却系统热阻太高，要么是电池散热速度慢得离谱" | **境外论坛评论，正文未打开，未证实** |

### 2.3 "空调费电"的真实归因（三条，与冷却系统设计无关）

1. **空调功率是绝对量**：电车电动压缩机 0.3-7kW，量级远大于油车；且低速时被摊薄——均速 20km/h 跑 100km 需 5 小时，1.5kW 空调即 +7.5 度/100km
2. **高配车耗电项多**：云辇-A **路面预瞄 + 后轮转向** + 座椅按摩 + 冰箱均计入"电器电耗"（NGA tid=47501750，146/191 楼，售后口径）
3. **这些项在 CLTC 循环里为零**——所以 CLTC 数字天然无法反映

> 帖内佐证（177 楼，Z9GT 车主 uid=26828094）："空调跟预瞄都开，续航是吹拉弹唱的 **6-7 折**；都关了，**8-9 折**。" → **是"耗电项多"，不是"某系统效率差"。**

### 2.4 判定

**论调存在（NGA 87 楼"迪子的电车空调电耗高"），但"冷却系统设计导致"这一归因不成立**——公开技术评价中比亚迪热管理是强项；空调费电的真因是**功率绝对量 + 高配耗电项 + CLTC 不计入**，属电车品类共性，非比亚迪特有缺陷。

## 3. 冲突记录（不得私选，必须并列）

> **比亚迪哨兵到底是"最省电"还是"垫底"？**
>
> - **说法 A**：[新浪看点 2026-09-09](https://cj.sina.cn/articles/view/7880068362/1d5b04d0a06801j6u2)——"**比亚迪汉的哨兵模式省电得多：实测一晚 1-2 度**，得益于优化后的低功耗图像处理芯片""最省电的是比亚迪汉"
> - **说法 B**：NGA tid=47501750 多位车主实测——比亚迪 **7-10 度/24h**；海狮 4-6 度/天（220 楼）；极氪 103 度电池对照仅 3-4 度/24h（98 楼）
>
> **判定：A 不可采信，B 为当前最优证据。** 三条理由：
> 1. A 属"看点资讯"频道**聚合内容**，数据来源为匿名"认证账号"，无原始测量；
> 2. A 所在一批内容**存在事实性错误**——同批 [新浪汽车·底盘手记 2026-09-19](https://k.sina.com.cn/article_7879996689_1d5af351106801dts4.html) 称"比亚迪哨兵尚未全量推送，预计 2026 年 Q1 上线"，而比亚迪[官方用户手册](https://www.byd.com)目录早已列有"1-6 哨兵模式"；
> 3. B 是多车主 + **多品牌交叉**（极氪 vs 比亚迪对照）的一致结果。
>
> **但 A 并非全错**：比亚迪**不同车型/代际**哨兵功耗差异确实极大（4-10 度/天），这与 §1.3"架构代际差"吻合。**"比亚迪哨兵"不是一个数，是一条分布。**

## 4. 对海豹08 的推论与缺口

- **推论**：海豹08 哨兵功耗大概率落在"高"那一档——高配（云辇-A/后轮转向/激光雷达多域控）+ 被指架构代际落后。NGA 楼主 10 度/天（n=1）与该推论一致。
- **缺口（关键）**：**海豹08 哨兵功耗无第三方独立实测**。懂车帝哨兵横评只覆盖乐道 L90（1.7 度/24h）、理想 i6（0.8 度/12h）、Model Y（5.74 度）、问界 M7（6.48 度）——**不含任何比亚迪车型**。
- **可执行验证**：同一车库、同环境、同电量区间，海豹08 与其他品牌各停 24h 不开哨兵 vs 开哨兵，测两次掉电量——单变量、一天出结果。

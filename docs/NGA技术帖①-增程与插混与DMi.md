## 二、技术原理层（可推演、帖内论证自洽）

### 2.1 两条路线的本质分野

| | 插混（含 DM-i） | 增程 |
|---|---|---|
| 发动机是否驱动车轮 | **是**（可直驱，也可与电机并联） | **否**，只发电 |
| 代表 | 比亚迪 DM-i、吉利（浩瀚/EM-i） | 理想 L 系列 |
| 系统复杂度 | 高 | 低 |
| 馈电高速 | 有直驱，可释放机头功率 | **油耗高、动力弱** |

（22 楼总结，帖内无争议）

### 2.2 ⭐ 关键纠正：DM-i 急加速并不是"发动机直驱"

**这是帖内最硬的一处技术纠正**（24 楼反驳 18 楼）：

> "插混的 DM-i **急加速的时候也是增程模式**！你不会以为直驱的时候急加速单档变速箱不解耦吧……"

**展开（42/43 楼）**：
- 急加速时**直驱解耦、不直连**
- 真正的功率峰值模式 = **发动机带发电机全力发电 + 电池大电流输出**
- **若直驱相连**，发动机转速被车速锁定，输出被限制，全靠电池补能 → 总功率反而小

→ **结论：DM-i 的"直驱"是高速巡航工况的经济性手段，不是动力爆发手段。** 18 楼"混动切到发动机驱动不如增程"的前提就是错的。

### 2.3 ⭐ 增程的真正短板：不是形式，是发电机功率

**53 楼给了机制级解释**：

> "增程的动力不如插混，**主要原因不是增程这种形式**，是**增程器连接的发电机的功率不够高**……大部分增程车的发电机功率不如增程器机头的最大功率，很多只跟增程器最优工作区间的功率相当。插混因为有直驱工况，可以把机头的最大功率释放出来。"

**并给了反例**：
> "**仰望 U8 发电机功率都有 180kW，所以仰望 U8 的亏电动力依然很强**，不会有点一条龙没电一条虫"

→ **这条把"增程弱"从形式之争降级为标定/选型之争**，是本帖最有价值的技术论点。

### 2.4 ⭐⭐ DM-i 失速的完整机制（帖内多位网友拼出来）

**问题定义**（21 楼）：三电任一元器件故障在比亚迪都可能被叫"失速"或"EV 受限"，各家叫法不同、本质相同。

**主因链条（24/80 楼，机制最完整）**：

1. **磷酸铁锂需要定期用慢充校准**——不校准会导致车机对电池真实容量**误判**
2. 误判放大在长途高功率场景：车机显示还有 **15% 安全值**，**电池实际可能已到 7%**
3. 此时若爆发超车、或常驻 120km/h 的 30kW+ 功率请求 → **7% 以内电量"上不来气"，功率受限**
4. **尤其发生在经济（ECO）模式**

**DM4.0 时期的可复现 BUG**（21 楼）：
- ECO 模式下发动机工作逻辑有问题，**不会根据电量主动拉高功率**
- **"只要强制把电池电量跑干，然后大脚油门就能出现"**（可稳定复现）
- 后比亚迪调整发电逻辑，基本消除
- 残留条件：**低电量 + 长时间 + 高速 + 爬坡**

**另一个诱因：小电池老化**（37 楼）：
- 电池年头长了电芯一致性变差，部分电芯衰减超平均
- **不限制功率则部分电芯承受不了高电压，增加自燃风险** → 所以厂家主动限功率
- **越是小电池车（尤其老款 55km 版）越明显**；小电池增程劣化更严重
- 呼应 30 楼："车质网最近投诉功率降低还在上榜"

**预防方法（80 楼，用户经验）**：
> "跑高速提前设置**大比例保电 + 运动/舒适模式**，几乎没见过案例"

### 2.5 多档 DHT 为什么被劝退

- 31 楼：**"单档插混和增程的逻辑更接近，多档插混和单档插混的区别更大"**——虽然都带直驱，但驱动逻辑完全不同
- 多档的代价：**成本更高、故障率更高、日常油耗电耗还略高**，而"同样排量下动力没多少优势"
- 30 楼对多档的历史评价：吉利搞过多档 DHT，**后来自己"跳车"改回单档（EM-i）主打省油**

### 2.6 前沿判断（帖内）

- **75 楼**："大电池 70–80 度、800V 平台的增程，你当它是台纯电也没啥问题，增程器就是个续航电池包"
- **79 楼**："CLTC 超过 300 的混动和增程，发动机工作的机会就不多了"
- **65 楼**（观点性）："5 代 dmi > 4 代 dmi > emi 及其他插混 >> 增程，大电池闪充 5 代 dmi 是目前版本答案"

## 四、口径与争议（不可当结论）

| 争议 | 双方 |
|---|---|
| **"很多人插混只充电不加油" vs "很多人插混只加油"** | 70 楼以自身为例（无固定车位、下班抢车位、干脆当油车开）；71 楼承认"真实情况就是这样"，但补"这也是为啥劝没家桩的直接买纯电" |
| **失速案例到底多不多** | 83 楼"小红书比亚迪失速案例一堆堆的，但很多贴主是新号，不敢说到底是不是真的"；82/84 楼车主自述 1.7 万公里"稳稳保电" |
| **"有电一条龙没电一条虫"** | 34 楼称 DM 馈电/富电性能一致性最好、零百几乎无衰减；36 楼说一代唐 DM 踩过这个坑、现在解决了 |
| 奇瑞"少一根轴" | 74 楼称奇瑞单档混动结构更简单、比比亚迪少一根轴，**未展开** |

**关于 83/84 楼的自我修正值得单独记**：**同一帖里，用户先看到大量"失速"帖，又发现发帖者多是新号 → 主动降级了自己的判断。** 这是本批帖子里少见的、健康的信息素养样本。

## 五、选车建议汇总（帖内共识）

1. **多档 DHT 直接排除**（2/6/7/31 楼）
2. 看**电池大小×三电**，别看发动机技术（7/31 楼）
3. 有小电池 + 少充电 → 单档插混；大电池 + 常充电 → 增程/插混皆可，**甚至直接纯电**（31 楼）
4. 无家桩、且不想折腾 → **直接纯电**（71 楼）
5. 想要动力 → 插混（67/76 楼：单档混动 70 以上电量多时，扭矩是电机+发动机之和）
6. **跑高速记得设大比例保电 + 非 ECO 模式**（80 楼）

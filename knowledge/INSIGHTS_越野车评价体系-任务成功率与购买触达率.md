## [2026-10-26] 越野车的两把尺子

### 归因层级

- **第一因（系统根因）**：越野车的主要买家从「任务执行者」变成了「形象消费者」，评价尺子随之从**任务成功率**换成**购买触达率**——即「试驾 20 分钟能感知、能拍、能传播」的性能被优化，「连续 N 小时不坏、坏了能自己修、被打中只损失一两人」这类不可拍的性能被挤出。不是车企走偏，是尺子换了。
- **加速器（放大因素）**：
  - **新能源**：电池能量密度约 0.15–0.25 kWh/kg，燃油约 12 kWh/kg，差 50–80 倍 → 带电的车轻不了 → 只能用大功率、独立悬挂、电控四驱来「补」；而补出来的恰好全是可营销项（零百、冲沙、攀爬打卡、涉水标称）。
  - **互联网**：可拍摄的性能被放大，不可拍摄的性能被淹没。
  - **法规与平台化**：行人保护、碰撞法规、平台通用件，共同把车推向「更高更宽更重更独立」。
- **未知变量（待观察）**：军用需求本身在分化——美军「远征军路线」（防护 + 高速 + 空运）vs 俄乌「消耗战路线」（便宜 + 数量 + 小目标 + 易修）。哪条会赢取决于未来战争形态，目前不可判。

### 核心锚点

1. **压强 × 速度互换律（本轮最有解释力的框架）**
   真实越野通过性不是单一指标，是 **接地压强 / 速度 / 行程** 三者的兑换。
   - 低压强路线：轻 + 大轮胎 + 可降胎压（UAZ-469 1.65t、LC70、GAZ-69、Haflinger 635kg）。
   - 高速路线：大动力 + 长行程 + 独立悬挂（悍马 113km/h、JLTV「70% faster off-road」）。
   - 达喀尔卡车跑 100km/h+、胎压不必很低也能过沙——说明「速度快了，压强就不是绝对必要」。
   - 因此用户原话里的「轻」不是目的，**「轻」是降接地压强的一条手段**；大胎是另一条；两者可叠加。
   - （工程内已有互证：`publish/jiangbo_comments.txt` 蒋波评论「对大部分越野来说，重量压根不是问题，压强才是」。）

2. **三个「不可拍」的性能**
   - **可修复性**：UAZ-469 的官方评价原话是 "it was able to drive in virtually any terrain and **it was very easy to repair**"（Wikipedia）。
   - **可损耗性**：俄乌战场摩托车被列为首选载具，理由之一是「一辆摩托被击中只损失一两人」（新华网/参考消息 2026-01-09）；乌国防部 2026-06-03 称摩托车与皮卡同为「战场上需求最大的车辆」。
   - **连续可靠性**：LC70 前后整体桥 + 后钢板弹簧，主销澳洲矿业/农民/公园管理（TopSpeed 2023-08）；UAZ-469B 1974 年三车登厄尔布鲁士（5642m），功率掉约 40% 但无一损坏。

3. **整体桥的三重价值，与「第二条路」**
   - 整体桥真正的价值不是「强度」三个字，是：① **没有半轴万向节角度枷锁**（独立悬架的行程上限被半轴角度锁死，见 `publish/篇1s-悬架选型铁三角...md`）；② **结构可修**（一根桥壳 + 两根半轴，坏了好换）；③ **载荷**（皮卡后桥是功能需求，不是越野妥协）。
   - **门桥是通往「行程自由」的第二条路**：Pinzgauer 用中央管状车架 + 全独立悬挂 + drop gear 门桥，离地 335mm、最大爬坡 80%、前后 100% 锁止差速器（百度百科/BAE 口径）。它没有整体桥，但解决了同一个问题——把半轴从角度枷锁里解放出来。
   - 所以「整体桥」不是唯一解，是**在「便宜 + 可修 + 载荷」约束下的最优解**。

### 反面证据（必须保留）

- **美军不是前后整体桥**：HMMWV 悍马为**四轮独立悬挂**，整备 2.36–2.68t，离地 410mm，最高 113km/h，1985 年服役（Wikipedia）。继任 JLTV 整备 6169kg（6.2 吨）、TAK-4i 智能独立悬挂、20 英寸轮跳（Oshkosh 官方）。美军从吉普（整体桥）→ 悍马（独立 + 高速）→ JLTV（独立 + 更重）的路径，恰恰是「用防护和速度换掉轻与简单」。
- **「轻」在真实高强度军用环境不是首要目标**：MRAP 为防护增重到 10–20 吨，台湾国防部《浅论美军轻型战术轮车发展概况》明写「因重量太重，在阿富汗越野作战时显得异常累赘」；M-ATV 约 30 吨、造价三倍于悍马、机械复杂（VOA 中文 2010-08）。
- **民用越野车没有「抛弃」整体桥**：LC70（前后整体桥 + 后钢板弹簧）1984 年至今仍在产；牧马人 Rubicon、212 T01 前后整体桥；坦克300 后整体桥。变的是**主流市场的占比**，不是技术存亡。
- **低压强路线在沙地的边界**：搜狐「越野e族」原文——「如果速度非常快，那么压强的大小就不是绝对必要的选项」，达喀尔卡车即为例。

### 已排除的假设

- ~~整体桥被淘汰~~ → 否，LC70/牧马人/212/UAZ 仍在产，只是退出主流。
- ~~军用 = 前后整体桥~~ → 否，美军 HMMWV/JLTV 是独立悬挂 + 高速。
- ~~轻是目的~~ → 否，接地压强才是目的；轻是手段之一。
- ~~民用越野车全在变重~~ → 部分成立（坦克300 2.15t、豹5 2.89t），但 Jimny 1.1t、Niva 1.15t 仍在售，只是非主流。

### 留待后续

- 俄乌「消耗战路线」（摩托 + 皮卡 + 可损耗）与美军「远征军路线」（防护 + 高速 + 空运）会不会合并出第三种形态？
- 电驱越野能否用「门桥 + 小电池 + 大胎」重构低压强路线？（当前电驱越野普遍走「大电池 + 大功率 + 独立悬挂」，正好落在用户批评的那一侧。）

### 确认的两条断言

1. **INEOS Grenadier 是前后整体桥（前后梁式桥）**：官方配置单写 "Carraro Beam Axles Front & Rear / Heavy Duty Coil Suspension / Full Box-Sectioned Ladder Frame / Permanent Four-Wheel Drive / Centre Differential Lock / Two-Speed Transfer Case"；轴距 2922mm、离地 264mm、接近角 36.2°、纵向通过角 28.2°、离去角 36.1°、涉水 800mm；车桥由意大利 Carraro（帕多瓦）供货，刹车 Brembo，悬挂/转向件 Frap（都灵）。官方博客的卖点原话是 "simpler to maintain and fix in the field"（现场维修更简单）。

### 新增的关键事实

- **美军新轻车仍是独立悬架路线，但路线在动摇**：JLTV A2 于 2025 年首批交付美军；eJLTV 为混动版；二者延续 TAK-4 系列独立悬架 + 轮边减速器（门桥）+ 可调车身高度。但 **2025 年 5 月美国陆军以预算与战略调整为由宣布暂停 JLTV 采购**，海军陆战队与空军继续（新华网转《国家利益》2025-07-29）。JLTV 整备 6169kg（6.2 吨）。

## [2026-10-26] 修正：门桥是正交维度，不是第三条路；「水多了加面」的闭环

### 修正一：门桥与悬架形式是正交的两个维度

上一轮把门桥写成「整体桥之外的第二条路」不准确。正确表述：**悬架形式（整体桥 / 独立）× 门桥（有 / 无）是两个正交维度**。

- **整体桥 + 门桥**：Unimog（前后整体桥 + 门桥）、G 500 4x4²（前双叉臂 + 后整体桥 + 前后门桥）——门桥在这里只赚**离地间隙**，因为整体桥本来就没有「半轴随行程摆动」的角度枷锁。
- **独立悬架 + 门桥**：悍马（断开式门桥 + 独立）、Pinzgauer（中央管状车架 + 全独立 + drop gear，离地 335mm、爬坡 80%）、JLTV（TAK-4 + 轮边减速器）、巴哈 Mason 前桥（前桥门桥 + 25 英寸行程）——门桥在这里赚**离地间隙 + 解锁半轴角度**两项。

关键的经济学表述：**整体桥的「半轴角度自由」是结构自带的、免费的；独立悬架的同一项自由要花钱买（门桥）**。所以「独立悬架 + 门桥」不是在「整体桥 vs 独立悬架」之外另开赛道，而是在补独立悬架的先天短板。这也解释了为什么这个组合集中在需要「行程 + 离地」的军用/竞技场景，而不是民用。

### 修正二：「水多了加面」的量化闭环

工程内已有的证据链：

- 赛道体系：**重量惩罚比 1.43**——四门/SUV 领域每 +1% 重量需要 +1.43% 马力来弥补。
- 派克峰体系：**爬坡功率税**——每多 100kg，无论马力多大先被扣 2-3hp 用于克服重力，没有下坡可以回本。
- `track/CONTEXT.md`：「技术越主动，机构越重，收益被重量税先扣一层」。
- `daily-touring`：NVH 堆料致重（隔音 → 质量↑）。

完整闭环（正反馈）：**增重 → 需要更大动力 → 动力总成更大更重 → 需要更强刹车/冷却/悬挂 → 更重**。而且这个闭环每一步的「解」都会写进配置表，成为下一个卖点。

符号翻转（本轮最重要的判断）：**同一个「重」，在三种需求下符号相反**——
- 民用：重是**买东西**（舒适、隔音、电池、智能），是正反馈，越重越豪华；
- 军用远征：重是**买防护**（MRAP 10–20 吨，代价是越野累赘）；
- 真野外工作/消耗战：重是**纯负债**（越重越陷、越难拖、越难修、越费油）。

### 修正三：「购买触达率」的归因上移

用户指出：这不只是互联网/新能源导致，更多是**民用商业竞争本身**。成立。根因应上移为：
**充分竞争 + 可传播指标 = 可拍性能压倒不可拍性能**。互联网和新能源不是病因，是放大器与当期介质。

工程内的营销口径实证（正好是这条机制的样本）：
- iTAC 官方宣传口径「精度提升 300 多倍」，算术口径是 85–128 倍（约两个数量级）；
- 豹5 的「三电机 vs 双电机」是营销口径，物理上是 P1+P3+P4 三台（P1 是发电机不驱动）；
- 各家在同一沙坡上「卖不同的技术故事」（篇3），都是厂商官方宣传口径。

### 收敛

**没有万能的越野车——三把尺子（接地压强 / 速度 / 可修复性）对应三类需求（民用 / 工作 / 军用），选车是选需求，不是选技术。**

- ~~购买触达率是互联网/新能源时代病~~ → 否，是商业病；时代只是放大器。

## [2026-10-26] 交付：三把尺子 × 四类需求对照表

> 用法：先定需求，再读对应行。跨行比较是错位——拿 LC70 的舒适性骂它、拿豹5 的可修复性骂它、拿 JLTV 的油耗骂它，都是拿错了尺子。
> 代价三问（ADR-0001 两步法）：**付在哪根轴？什么形式？何时兑现（即时/延迟）？**

### 表下两条注

1. **互换律**：压强 ↔ 速度可互换。达喀尔卡车 100km/h+ 巡航、胎压不必很低也能过沙；UAZ/LC70 用低压强大胎换速度。同一地形两条路都能到，账不同——但都有各自的兑现时点。
2. **「重」的符号**：民用重＝买东西（舒适/电池/智能）；军用远征重＝买防护；工作重＝买载荷；只有真野外消耗战的重是**纯负债**。这是四行之间唯一不能互换的东西。

## 待充实点（2026-10-26 用户判定「结论和内容还不是很充实」，暂缓）

### 结论层缺什么

1. **「购买触达率 vs 任务成功率」还没有可操作的度量**：现在只是两个名字。需要定义各自的一两个代理指标（例如：购买触达率≈试驾 20 分钟内的可感知项数量/配置表可列项；任务成功率≈连续工时无故障率/现场可修复率/单位任务油耗），否则无法用来判断具体车型。
2. **军用「远征 vs 消耗战」的分界还不够硬**：目前是按「有没有制空权/空运能力」切，但这两者可能只是同一支军队在不同战争阶段的两种状态，不是两类军队。需要找更本质的切分变量（战场透明度？后勤距离？装备补充速率？）。
3. **「工作」一行太粗**：林业（窄、轻、林道）、矿业（载荷、耐久、长里程）、救援（速度 + 通过性）、农业（低速扭矩 + 低压强）对三把尺子的权重差很大，现在被压成一行。
4. **「民用」一行太粗**：城市 SUV（不要越野）、硬派越野（周末真去野）、电驱越野（新势力）是三拨买家，采购逻辑不同。

### 内容层缺什么

5. **缺一张「典型车数据底表」**：每台典型车的整备质量、原厂胎径/胎宽、接地压强估算、悬架形式、门桥有无、差速锁、维修工时/保养间隔——现在表里只有车名，没有可复算的数。
6. **缺「代价兑现时点」的量化**：四类载体里，质量能算（kg）、热能不能算（降额百分比）、复杂度/控制保守只能定性。要么补可量化的代理，要么明确写「定性」。
7. **缺「民用商业竞争 → 可拍性能」的机制实证**：现在只举了 iTAC 300 多倍、豹5 三电机两个例子，需要一条更完整的链条（发布会话术 → 媒体转述 → 用户认知 → 竞品被迫跟进）。
8. **缺「俄乌消耗战」的一手数据**：目前只有乌国防部摩托车采购与「一辆摩托损失一两人」的定性表述，缺少车辆损失率、单车任务架次、维修周转时间这类可算的数。

### 结构层缺什么

9. **四类需求是不是互斥**：一辆车可以同时被军队和民间采购（Grenadier、LC70、Hilux），说明「需求类型」可能不是车辆属性，而是**使用契约**（谁买、怎么用、坏了谁修）。这一点如果成立，整张表要改成「契约 × 尺子」而不是「需求 × 尺子」。

# 中国四代坦克或选择双人体制 驾驶员与炮长该减掉谁

> 来源：https://mil.sina.cn/sd/2018-03-02/detail-ifwnpcnt1224818.d.html | 日期：2018-03-02

记得几年前当阿玛塔坦克刚刚问世时，我曾撰文：阿玛塔的三人底盘乘员舱布局算不上什么四代坦克。未来坦克只有进化到了双人坦克才能在总体性能上较目前的三代坦克有质的飞跃，才能算的上真正的四代坦克。不过后来随着时间的推移，我发现即便是实现了双人坦克也未必能称的上四代坦克。

前些天看到又有人拿双人坦克出来说，因此我觉得有必要把一些新的认识分享给大家。

平心而论阿玛塔坦克是一辆不错的坦克，乘员底盘集中布置无人炮塔的设计确实非常的科幻，但是离四代坦克的距离还很远。主要的问题有以下几个方面。

现在主流的观点认为，因为坦克重量的上限被限制的很死，所以基本上以尽量减小正面投影的办法来提高坦克的防护性能。阿玛塔坦克也是如此，将乘员集中布置在底盘之中是期望用无人炮塔剩下的装甲重量来加强底盘的防护。

不过这个思路看着简单，但实现起来却并不容易。从人机工程的角度，炮手和车长需要一个舒服的姿势来不停的进行观察，他俩不能像驾驶员一样坐的太低。为此阿玛塔坦克的底盘要比T-90什么的高了不少。底盘在增加三人乘员舱之后又变长一节，上世纪90年代的很多双人坦克概念里都是用缩短的发动机舱来弥补乘员舱多出来的长度，而阿玛塔的发动机舱反而又大了。又高又长的底盘所带来的重量的增加抵消了不小采用无人炮塔省去的重量，而且俄罗斯坦克又不愿意放开坦克总重量的限制，因此最终坦克底盘正面增加的防护并没有多少。

写到这里有人会说，把三个乘员并排坐在一起底盘长度不是又能缩回来一些了么。其实却是是这样，三个人挤挤却是并排着能坐的下。不过防护性能的角度来讲这样又是非常不好的。把车长和炮长从战斗室内挪出来的初衷是好的，但是将三个人集中在一起又增加了集体被报销的风险。底盘的正面问题不大，但是乘员舱的侧面必须有很强的防护。因为如果侧面被击穿，那么车里的三个人就是一串烤肉。坦克的车宽是有限的，三个人并排坐进去之后，就没有多少的宽度可以用来增加装甲防护了，而如果是双人乘员的话，情况则好得多。

双人制坦克的问题在于，到底两个人的角色如何分配。坦克从五个人减到四个人取消了电台兵，从四个人减到三个人取消了装填手，而从三个人减到两个人又能减掉谁呢？对此当前主流的观点有两个。

一种是减掉炮长，用自动化瞄准和AI技术来代替炮长的作用。这样做实现起来比较简单，但是效果未必会好。虽然车长和炮长是一个主观察一个主瞄准，但是必要时他俩还能互为备份，这一点在长时间高强度的作战中尤为重要。把他俩功能合二为一，那车长的负担实在是太重了。

另外一种是减掉驾驶员，利用自动驾驶和AI技术大大减轻驾驶的劳动强度，人员只需必要的干预即可。对于这种思路持反对意见的人认为自动驾驶对于坦克来讲不太可能，但本人想说的是，这里的自动驾驶只是将驾驶员从需要专注的体力劳动中解脱出来，让其有时间能操控武器或者协助车长处理一些信息什么的。

然而，还有人认为未来战争的信息处理任务繁重，并且将赋予坦克更多的职能。比如如果坦克与无人机或者无人作战平台实现交联，并协同作战的话，坦克可能会增加一个操控员或者信息员什么的角色。这样一来，未来到底是几人制坦克就不好说了。

总之，本炮霸认为，未来坦克的坦克究竟几个人这件事现在还说不清楚。两人替代三人，防护和轻量化可以搞；如果还是三人，未必还会用底盘乘员舱集中布置，并且很可能角色会重新定义；如果再赋予更多的要求，比如侦察，或者指挥无人平台，那么坦克上的人数回到四个或者五个都是可能的。（作者署名：炮霸707）

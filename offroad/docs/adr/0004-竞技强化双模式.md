# "竞技强化及安全系统"双模式：竞技加分 / 民用展示

该一级指标的定位分两种模式：

- **竞技场景**（沙漠短冲刺、沙漠长耐力、戈壁竞速、砂石竞速、高原山路）：作为第 7 个一级指标参与评分，以附加分形式叠加在原 1000 分之上，不挤占原有指标份额。
- **民用场景**（日常通勤、戈壁穿越、岩石/攀爬、丛林/泥泞）：不参与评分，仅作为装备信息附录展示，由用户自行参考。

考虑过的替代方案：
- 统一参与所有场景评分——被否决，民用场景中液压千斤顶/刹车冷却等项对用户无意义，且民用场景已有原 1000 分体系。
- 完全不参与评分仅为展示——被否决，竞技场景中这些装备是决定完赛/退赛的核心变量。

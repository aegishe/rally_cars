# 坦克 500 Hi4-Z 官方技术口径速查

> 整理时间：2026-09-01。**以下所有口径均来自坦克 500 Hi4-Z**（2024-12 预售 / 2025-01-01 上市）的官方发布与官方人员访谈，引用时标注车型"500 Hi4-Z 官方口径"，勿串到 700 Hi4-Z 或其他车型。用途：篇5 / 完美电驱 / offroad 谱系写作的数据引用集。

| 口径 | 值 | 出处 |

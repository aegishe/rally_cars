# 柴油混动 — 架构适配性分析

> 从 `offroad/CONTEXT.md` §动力架构 > 柴油混动（补充）独立拆分。不作为独立维度进入打分体系。

## 核心逻辑

柴油机低扭好、重量大、功率小、NVH 差。在混动时代，电机已覆盖低扭短板（旧逻辑"柴油=低扭之王"不成立）。

## 分架构适配性

| 混动架构 | 适配结论 | 原因 |
|---------|---------|------|
| **P2 并联** | ⚠️ 仅在攀爬/泥泞/丛林有正差值 | 亏电低速场景低扭减少变速箱换挡有优势；高速场景峰值功率短板暴露。目前无量产产品（长城规划中） |
| **DHT 多档** | ❌ 越野 SUV 无立足点 | 柴油转速红线限制高速直驱档位。奇瑞仅用于皮卡（拖拽+120km/h 极速足够） |
| **单档混动** | ❌ 不可行 | 柴油转速窄，单档直驱速比不匹配 |
| **增程式** | ❌ 无应用 | 柴油增程器效率高，但 NVH + DPF + 重量三重惩罚 |

## 底层类比

柴油在商用车/工程车（不要高速、成本敏感）有优势。

越野是乘用车与工程车的交集：
- **低速越野场景**：柴油有物理优势
- **高速竞技场景**：汽油是唯一解

## 底层机制证据（内燃机第一性）

「功率小、转速红线低、高速直驱档位受限」的机制根因，由视频 [BV1NYtq6WE2W](https://www.bilibili.com/video/BV1NYtq6WE2W)《柴油机为什么没有爆发力？》（无尽的探索-蒋波，2026-09-05，直播回放 17.4min）给出：

- **因果链**：压燃（被动点火）→ 必须高压缩比 + 长行程 → 转速低、攀升慢、扭矩平台窄、转速储备低 → 爆发力弱、转速红线低。这是结构特性，不是调校能补。
- **同排量对照论据**：宝马 B57 柴油（84×90，620 Nm）vs B58 汽油（82×94.6，450 Nm）——B58 行程比例反而更长，定位却是「平顺省油」，特性几乎对调后零百仍差 0.x 秒、高速段（100-200）被明显拉开，证明差距是结构性的。

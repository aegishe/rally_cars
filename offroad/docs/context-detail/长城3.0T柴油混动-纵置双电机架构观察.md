## 一、已确认事实（纯柴油版）

- **3.0T 四缸柴油机**（注意：四缸，非 V6；单缸 750cc 大单缸）：170kW / 620Nm
- 对比自家老 2.4T 柴油（~135kW/481Nm）：功率 +26%、扭矩 +29%、零百 +20%、NEDC 油耗 -5%
- 油耗：Tank 500 **7.1L** / Cannon Alpha **7.3L**（NEDC）
- Tank 500 澳洲版 **130L 油箱** → 理论续航 ~1800km
- 澳洲售价 <6.5 万澳元；对标丰田 HiLux/Prado、福特 Ranger/Everest
- 定位：拖拽（3.5t 级）、长途穿越、越野（[CarExpert](https://www.carexpert.co.nz/car-news/gwm-opens-order-books-for-new-620nm-turbo-diesel-tank-500-and-cannon-alpha)）
- 扭矩密度 3.65 Nm/kW（620/170），同级最高（福特 3.0 V6 柴 3.26、丰田 1GD 2.8T 3.33、五十铃 3.0T 3.2）——纯重载取向标定
- 高压缩比线索（用户观察）：大单缸+高压缩比 → 低转燃烧稳定 → 扭矩平台宽（预期 1500-3000rpm 满扭），"压缩比大→低扭更好"因果链：压缩比→着火延迟短/低转稳定，不直接决定扭矩绝对值（绝对值靠增压+喷油）
- ⚠️ 澳洲版是否为分时四驱待确认（山海炮国内为 4A+MLOCK，澳洲口径可能不同）

## 二、混动架构观察（视频转述，待实锤）

动力流（纵置非承载平台）：

```
3.0T柴油机 → [P2电机] → AT变速箱(液力变矩器疑似取消) → [新电机] → 分动箱 → 前后轴
                                      ↑ 可脱开                       ↑ 可脱开
```

1. **P2 保留**：发动机-变速箱间仍是既有 P2 电机（沿用 Hi4-T 路线）
2. **液力变矩器疑似取消**：起步/蠕动/换挡缓冲的变矩器职能移交电机——起步靠 P2/新电机，换挡靠新电机输出端补扭，低速蠕行纯电
3. **变速箱-分动箱之间新增电机**：拓扑近似 Hi4-Z 的 P3 位置（变速箱输出端），但驱动**分动箱**（前后轴），中央机械四驱保留——不同于 Hi4-Z 的 P4 后桥独立电机
4. **可断开变速箱、新电机直驱**（厂商口径）：纯电模式发动机+变速箱全停，拖曳损失最小化

### 驱动模式矩阵（推演）

| 模式 | 动力流 | 变速箱 | 意义 |
|---|---|---|---|
| 纯电 | 新电机→分动箱→轮 | 脱开静止 | 拖曳损失最小，低速精确蠕行 |
| 串联 | 柴油机→P2发电→新电机→轮 | 脱开 | **柴油机锁高效区恒转速发电**，绕开低速低效区与档位匹配约束 |
| 并联 | 柴油机+新电机→轮 | 接合 | 短时大功率请求 |
| 直驱 | 柴油机→变速箱→分动箱→轮 | 接合 | 中高速巡航主力 |

## 三、关键推演（待实锤验证）

- **双电机 = 亏电下仍有串联模式**：Hi4-T（P2 单电机）亏电只能机械直驱的铁律被打破，柴油机在任何场景可锁高效区发电
- **绕开 DHT 档位匹配死结**：串联路径完全绕过变速箱档位，"柴油红线低、多档位匹配不了"的老问题被结构性规避（长城用 AT 而非 DHT）
- **"变矩器工况"被电机全面接管**：起步（电机零转速起步）、换挡（输出端电机补扭，无变矩器缓冲时 AT 平顺性全靠电控+补扭，标定难度高）、蠕动（纯电）
- **新电机持续功率是命门**：越野低速 = "持续数分钟+无撞风"最差散热工况（电机功率瓶颈三维框架），低速主力电机必须有大持续功率+独立散热，否则热衰减；叠加坦克 700 环塔散热教训（多散热器布局为短板），混动版散热压力更大
- **重量惩罚加重**：双电机+双脱开机构+大电池（Hi4-T 为 37.1kWh 级），3.0T 柴油机本身比汽油重 30-50kg 基线，整备质量 2.7t 级风险

## 四、与柴油混动-架构适配性分析.md 的碰撞

| 原结论 | 新架构冲击 | 判定 |
|---|---|---|
| 电机已覆盖低扭短板，柴油优势被抵消 | 柴油价值从"低扭"转向"**高效发电平台+中高速直驱油耗**" | ⚠️ 需修正逻辑 |
| P2 柴油仅攀爬/泥泞/丛林有正差值 | 低速优势扩大：纯电精确蠕行+串联兜底+无换挡；串联路径绕过档位匹配 | ⬆️ 正差值扩大 |
| DHT 多档对柴油无立足点 | 不冲突（长城用 AT）；变速箱可脱开绕开转速-档位匹配死结 | ✅ 保留+补注 |
| 增程对柴油 NVH+DPF+重量三重惩罚 | NVH：串联模式转速自由可标定规避，论点弱化；DPF：发电工况持续中高负荷，再生条件反而更好；重量：**惩罚加重** | ⚠️ 部分推翻 |
| 高速竞技场景汽油是唯一解 | **核心不动**：电机短时补功率坐实"高速大功率仅短时则柴油可行"；持续小时级高速大功率仍是物理禁区 | ✅ 保留 |

**总体**：该架构不推翻"高速竞技汽油是唯一解"，但把柴油低速底盘从"勉强可用"抬到"最强场景"，并新增工程文档缺失的架构类型——**纵置双电机串并联（P2+变速箱后电机）+机械四驱**（Hi4-T 与 Hi4-Z 的中间形态）。

## 五、待实锤/参数缺口（后续更新按此清单核对）

1. 新电机：功率/持续功率/峰值扭矩/最高转速（**当前完全未知**，上轮 620Nm 归因已更正为发动机参数）
2. 液力变矩器是否真取消；AT 换挡标定方案
3. 脱开机构形式（离合器 or 牙嵌）、位置
4. 电池容量（Hi4-T 基线 37.1kWh）
5. 分动箱是否保留 4L + Mlock；新电机是否参与 4L 扭矩放大
6. 纯电速度上限（新电机转速 vs 传动轴转速）
7. 澳洲版四驱形式（分时 vs 4A+MLOCK）
8. 混动版油耗/续航实测

## 六、对打分体系的意义（建议，待实锤后落实）

- 动力架构分类新增候选："**纵置双电机串并联（P2+变速箱后电机）**"——介于 P2 并联与 P1+P3+P4 混联之间，机械四驱保留
- 柴油混动适配性分析更新方向：低速正差值扩大、高速禁区不变、串联模式修正增程三重惩罚中的 NVH/DPF 两项

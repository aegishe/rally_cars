# 限滑与蠕行：术语细节

> 从 `offroad/CONTEXT.md` 拆出的 iTAC / CCO 超长词条全文。CONTEXT.md 只留紧凑定义，此处保留完整辨析与来源。

## iTAC（智能扭矩控制）全文

比亚迪智能扭矩分配系统，主用于双电机车型，电控实时调整**前后轴**扭矩。感知复用**电机旋变传感器**做**轴速**感知（电机转子转速=差速器输入轴转速，12 位解码 = 每转 4096 计数）——"精度提升 300 多倍"是比亚迪 iTAC 官方宣传口径（按 4096÷(32~48) 的算术口径是 85-128 倍、约两个数量级），>200Hz，可提前约 50ms 预判打滑趋势；执行用**扭矩转移/降扭/输出负扭矩**替代 ESP 制动（驱动域、不产热）；_粒度_：双电机版三者均为**轴级**操作（作用于前/后轴整体，开放差速器等扭矩拆不开左右轮），轮级（单轮）降扭/负扭矩需**每轮独立电机**（分布式四电机如易四方、或同轴双电机如易三方后轴），双电机 iTAC 不具备。_注_：Rivian 四电机/后桥双电机硬件等价（每轮独立电机），但其扭矩矢量重点是公路操控与机动性（Kick Turn，Tank Turn 从未发布），无比亚迪式轮级降扭/负扭矩做越野限滑、爆胎稳定的标定——每轮独立电机只是必要条件，非充分条件。_边界_：旋变测的是**轴**转速，只覆盖**轴间**（前后轴）打滑判断与扭矩分配；**轮间**（同轴左右轮）区分靠每轮独立的轮速传感器，双电机版 iTAC 不覆盖轮间（官方口径"未来目标四电机车型以实现更精准的轮间控制"）。因此豹5/豹8 轮间限滑仍是"牙嵌锁 + ESP 制动"两条老路，持续脱困仍会热衰减。_避免_：把 iTAC 的轴间驱动域优势（扭矩分配、降扭不产热）与轮间制动域短板（发热）混为一谈，也不要把"暴力模式"当限滑（见 perfect-e-offroad CONTEXT）。_定性_：市场监管总局沙盒监管试点（2023）将 iTAC 归为"智能扭矩控制"，官方表述是"ESP 的四驱前置升级版/TCS 再升级版"；与华为 DATS、长城 iTVC、极氪 ZVC、长安 DVT 同类——轴间扭矩控制是新能源架构的行业标配，比亚迪的差异在**电机旋变感知精度**与**越野标定深度**，而非"独门技术"。_命名_：同一"前后轴扭矩分配"能力，比亚迪在轿车线叫 iTAC（2022 首搭海豹），在越野线方程豹豹5（2023）叫"**能量中锁**"——即"三把锁"的第三把，**无实物**，官方口径 10ms 内完成前后轴扭矩转移（比机械锁快约 30 倍）。两者是同一驱动域能力在不同产品线的两个名字，而非两种技术。

## CCO（蠕行控制）全文

长城低速越野巡航控制——系统自动控制**扭矩输出+制动**（扭矩输出线性），驾驶员只把握方向盘，按设定稳速通过坏路/爬山/沙漠。二代 CCO（官方视频演示）一键进入（安全带+一按，4L 或 4H 越野模式均可），支持 **R 挡接入**实现脱困倒车，4L+差速锁配合左右摇摆脱困（针对"沙漠陷车但未托底、新手不会操作"场景）。_定位_：与比亚迪暴力模式、iTAC 为三个独立维度——CCO 接管**操作层**（油门/刹车由系统代管，解决"会不会操作"），暴力模式是**标定层**（低速峰值扭矩 <2km/h + 滑移率≤3% + 轴间扭矩分配的联合标定，非限滑），iTAC 是**响应层**（轴间扭矩分配，驱动域限滑）。_避免_：把 CCO 混同于陡坡缓降（后者只控速、无 R 挡接入、无摇摆脱困标定）；也不要把"暴力模式"当限滑（见 perfect-e-offroad CONTEXT）。_来源_：长城技术中心官方视频 BV1BUtA65ETM《不会控油门，也会玩越野》，字幕见[项目根目录](<../../不会控油门，也会玩越野-BV1BUtA65ETM.txt>)。

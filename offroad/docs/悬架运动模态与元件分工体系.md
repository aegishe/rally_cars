## 一、四类元件，各管一段频谱

悬架系统不是"弹簧+避震"两件套，而是四类元件各管一段频率。任何"某悬架行不行"的判断，先落到"它动的是哪类元件"。

| 元件 | 物理职能 | 主责频段 | 越野视角 |
|------|---------|---------|---------|
| **弹簧/空悬** | 静载支撑、车身高度、姿态刚度基础 | 0-2Hz | 空悬调高度过障碍、双腔调刚度 |
| **阻尼器（避震）** | 能量耗散，速度相关力 | 2-15Hz（CDC 半主动主战场 4-8Hz） | 飞跳落地防击穿是它的活 |
| **几何/防倾杆** | 运动学 + 被动耦合：anti-dive/squat、toe 特性、侧倾刚度 | 0-2Hz（刚度）/ 全域（运动学） | 防倾杆限制行程是越野负资产 |
| **主动执行器** | 主动出力：举升/锁侧倾/补偿扭曲 | 0-4Hz 姿态带 | 享界式只占 roll 一格 |

**判读口诀**：弹簧管"多重"，阻尼管"多快"，几何管"往哪动"，主动执行器管"往哪顶"。

## 二、核心矩阵：运动模态 × 谁在管

悬架行程的任意轮跳组合可分解为四模态：**Heave（四轮同相）/ Roll（左右反向）/ Pitch（前后反向）/ Warp（对角反向）**。单轮上下 = ½ Heave + ½ Roll，是混合模态，不是基础模态。

| 运动模态 | 弹簧 | 阻尼器 | 几何/防倾杆 | 主动执行器 |
|---|---|---|---|---|
| **Heave 垂跳**（减速带、飞跳落地） | 承载+刚度 | 压缩/回弹阻尼 | 防倾杆**不介入**（同相运动） | 全主动可反向举升；享界式不管 |
| **Roll 侧倾**（过弯/变线/侧坡/横风） | 左右刚度基础 | 低速段辅助 | **防倾杆主责** | 主动稳定杆 / 6D 液压锁定 / 全主动 |
| **Pitch 俯仰**（加减速、爬坡） | 前后刚度 | 压缩回弹比 | **anti-dive/squat 几何** | 全主动（PAR 抗俯仰招牌）；享界式不管 |
| **Warp 扭曲**（交叉轴、炮弹坑） | 行程储备 | 几乎不介入 | 防倾杆是**负资产**（绑死行程）→ 断开 | 6D 互联补偿 / 主动断开释放 |

**关键观察**：防倾杆只在 Roll 里是正面角色，在 Heave 里中立、在 Warp 里是负资产——这就是"可断开"的价值来源，也是享界把主动化选在防倾杆上的原因。主动执行器的各路线差异，本质是**在这个 4×4 矩阵里占几格**：

| 主动方案 | 占格 |
|---|---|
| 全主动悬架（PAR/直线电机） | 四格全占（理论） |
| 6D 液压互联 | Roll 被动锁定 + Warp 补偿（半主动） |
| 享界式主动稳定杆 | 仅 Roll 一格 + 断开开关 |
| 48V 轮边 CDC | 占的是**阻尼器**那一行（半主动，不出力） |

## 三、避震（阻尼器）自己的一维：频率谱

阻尼器是唯一覆盖 2-15Hz 全带宽的元件，按频率分层是它的专属账：

| 频段 | 现象 | 归谁管 |
|---|---|---|
| <1Hz | 高度、静轴荷 | 空悬/弹簧 |
| 1-2Hz | 簧上共振（晃） | 弹簧刚度 + 防倾杆 + 主动执行器 |
| 4-8Hz | 人体敏感区（颠、抖） | **CDC/阻尼器主战场** |
| 10-15Hz | 簧下轮跳（wheel hop） | 阻尼高速段 + 衬套 + 簧下轻量化 |
| >20Hz | 路噪结构传递 | 衬套、轮胎 |

**判读**：半主动 CDC 的 1ms 级响应用在 4-8Hz 是最优匹配（阻尼是速度相关力，恰好是这个频段的耗散需求）；把毫秒级响应吹成"替代全主动"是偷换频率段——姿态控制（1-2Hz）要的是**力**，阻尼器给不出持续力。

## 四、避震特有的两个端点任务（行程极限）

阻尼器的另一份专属账在行程两端——这是位敏阻尼（position-sensitive）的地盘，速度相关阻尼管不了：

- **压缩端触底**：缓冲块 → 液压缓冲（Bilstein JCO/RCO 内置、K-MAN 外置）→ 位敏阻尼的"无底感"。篇1 里环塔（K-MAN 单活塞可调 + 外部液压缓冲块 + 限位带）与达喀尔（Bilstein Black Hawk 三活塞五分区内置）的"架构代差"就写在这一格。
- **伸展端全拉伸**：限位带 + **腾空预加载**（卫士 6D 工程采访口径：检测四轮全拉伸 → 预加载着陆阻尼）。

**判读**：飞跳落地是 Heave 的冲击版（模态归属），但保护动作是避震的活（元件归属）——模态与元件是两个正交的坐标，混着说就会出"全主动管飞跳"这种半对半错的表述。

## 五、越野场景的两个特殊态

- **断开态**：攀爬/交叉轴时解耦防倾杆或稳定杆，释放行程——6D 断互联（越野时断开全联通管路）、享界断稳定杆，同一件事的两种实现，一个液压一个电动。
- **预加载态**：腾空检测 → 提前加阻尼等着陆（§四 伸展端任务的动态版）。

两个特殊态的共同点：都是**"先识别状态、再切换策略"**的链路——这正是篇1s 被动位敏"泛用性悖论"反过来的软肋（不认场景只认物理量 vs 认场景才有策略）。

## 六、与既有框架的衔接

1. **模式解耦（篇1s §四）**：四元件各管一段频谱、四个模态各有主责——被动侧的解耦（AMG One 杆系 / Triplex 第三阻尼器 / FRIC 液压网）是把"混在一个元件里的多个职责"拆开；本文的矩阵是同一个思想在**元件层**的表达。
2. **主动 vs 被动（篇1s §六）**：主动执行器只在 0-4Hz 姿态带出力，4Hz 以上全部让位给阻尼器——"主动悬架管细碎颠簸"是厂商话术，高频是 CDC 的活。
3. **享界方案定位**：主动执行器占 Roll 一格 + 断开开关，其余三格（Heave/Pitch/Warp 的被动基础）靠弹簧/阻尼/几何传统分工——所以它轻、它便宜、它绕开三大路线的三刀（能耗/簧下/散热），代价是那三格的**能力上限被锁死在被动元件手里**，且断开/连接的切换策略在越野中间态（高速戈壁既要行程又要侧倾支撑）有误判风险。
4. **信源分层**：§一/§二/§三 为车辆动力学常识层（教科书口径）；§四 的 K-MAN/Bilstein/6D 细节为项目已有素材层（篇1/篇1s 信源）；§五/§六 的享界对照为分析推断层，引用时标注"分析推断"。

## 七、待补缺口

1. 主动稳定杆的**持续扭矩 vs 瞬态扭矩**口径未披露（享界素材只有 120ms/1400Nm 峰值）——"定圆持续撑住"与"变线瞬间顶一下"是两笔账；
2. 断开-连接切换的**迟滞与平顺性**（NVH 层面的"咔哒感"）无公开数据；
3. 6D 液压互联与主动稳定杆**组合使用**的重量/成本/复杂度账，目前只有定性推演。

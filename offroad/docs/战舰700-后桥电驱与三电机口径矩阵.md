## 三、可复算的账（引用数字时照此写）

### 3.1 功率账：830kW 的分解

```
系统综合 830kW = 前 P3 230kW + 后双 P4 440kW（2×220）+ 2.0T 发动机 160kW   ✅ 自洽
```

三者相加**恰好等于**官方系统综合口径，与本项目"分项之和 = 综合标称"的自检项吻合。⭐ 这条同时反证后桥必须是 2×220kW 而非其他值——否则 830 凑不出来。

### 3.2 扭矩账：13920N·m 的分解

```
整车轮端 13920N·m
  ├─ 后桥：2 × 4500 = 9000N·m（星驱自述）
  └─ 前桥：13920 − 9000 = 4920N·m（反推）
```

**反推减速比交叉验证**（两个独立算出的比值互相印证层级判断）：

| 轴 | 电机轴端 | 轮端 | 反推减速比 |
|---|---|---|---|
| 后桥（单体） | 280N·m（反推 = 560/2） | 4500N·m | ≈ **16.1** |
| 前桥 | 350N·m | 4920N·m | ≈ **14.1** |

两个比值同落 **10–20** 区间（轮边减速器典型值），互为印证 → **4500N·m 确为轮端值，非电机轴端值**。

### 3.3 ⚠️ 口径校正：9000N·m 的双重含义（本次最重要产出）

项目旧记（`opencode-archives/吉利越野架构对比比亚迪DMO.md` 等多处）引官方原话：**"单轮扭矩最高可以放大 200%，达到 9000N·m"**——但无底层参数，无法判断 9000 的层级。补上星驱的 2×4500N·m 后机制清楚了：

- **常规状态**：后桥每轮 = 4500N·m（一台电机管一个轮）
- **硬锁耦合后**：两台电机扭矩叠加到有附着力的一侧 → **单轮独得 9000N·m**（= 4500 的 200%）
- **同时**：9000N·m 也等于"后桥双轮常规合计"

**结论**：9000 这个数在两种口径下都出现，**数值相同、含义不同**。引用必须写清是**"单轮上限（锁止工况）"**还是**"后桥合计（常规工况）"**，不得混用。项目默认引用口径 = **"硬锁耦合后单轮上限 9000N·m"**。

## 五、口径陷阱备忘

1. **"50:50 前后轴荷比"是架构级营销字段，不是某一台量产车的实测轴荷。** 该表述出自吉利"原生新能源越野架构"2026-04 北京车展首发口径（[新华网](http://www.news.cn/auto/20260426/f0d654d8036340a28b7e17273cf208fd/c.html)、[经济参考报](http://jjckb.xinhuanet.com/20260430/37a3adb75a754030b98e843a66a605f6/c.html)）；同一说法在 GEA Evo 平台的银河 M7（口径为"**接近**50:50"）、星耀7 MAX 上复用。**8-28 首搭战舰700 的 GTA 正式技术发布稿没有重复该数据**，只给了"车身重心 700mm"（**高度**，非纵向位置）。
2. **不得用浮水/涉水姿态反推静态配重。** 浮水艏倾角读的是"重心与平浮浮心的相对偏移"，而船体浮心位置是未测量量；战舰700 前舱不密封（IPX8 保的是三电，不是整车），浮水时前舱充水丧失浮力 → 浮心后移，量级足以独立造出 2.5–4° 艏倾。仰望 U8 前舱布置/重量/推进方式全不同而浮水姿态一致，佐证主导项是浮力舱布置的**类别共性**，非各家配重偏好。
3. **"1128 马力 / 3.95 秒" 不等于功率兑现。** 0-100 需动能 1.11MJ，用时 3.95s → **等效恒定输入功率仅 281kW，占标称 830kW 的 34%**。瓶颈是 2.88t 总重 + 越野胎附着 + 起步功率落地，与纵向重心分布无关（轴荷转移按官方重心高度 700mm 估算约 500kgf 后移，起步瞬间后轴载荷反增）。

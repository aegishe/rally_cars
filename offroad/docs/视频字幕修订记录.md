## 二、新增实证信息（字幕提炼，未写入主文档的备用素材）

1. **官方队 37.1kWh 大电池 PHEV 压到 3 吨以内**（"靠近陆巡的重量"，BV12WorBTEhG）——官方减重工程的数据锚点
2. **民间队重量**：不加油（水油液满）近 3.3 吨、满油 3.6 吨、加两人 3.7 吨（科曼自述）
3. **悬挂行程**：35 胎 → 255mm（FIA 新规，与卫士一致）；34 及以下胎 → 270mm。科曼承认"后悬挂行程吃亏（对比 T1+ 的 350mm），但为达喀尔规则验证不敢放大"
4. **传动**：35 胎 → 齿比 4.1→4.556；传动轴/分动箱/变速箱/差速器/半轴全原厂；全程只坏一根半轴（SS5 人为锁止打方向挂地所致）
5. **分动箱**：拆 4A 多片离合器改分时四驱（高四+后驱为主，低四保留脱困）
6. **刹车**：主泵原厂（电助力，混动回收标定需要），分泵改车内可调前后刹车比（对齐卫士/陆巡），加液压手刹
7. **空调**：原厂空调保留（卫士改装换了客舱专用 unit），配比把更多功率分给电池散热
8. **机盖进气**：结合陆巡和卫士的方式（开孔+高位进气）
9. **保电实证**（科曼车手）："任何新能源车死乞白赖开都不可能完全保电……但坦克 700 没关系，3.0TT 源源不断"——电量到 10%+ 无动力衰减感，无需停车发电
10. **减震**：科曼中东版二代赛用（液压缓冲+回弹缓冲+非线性阀系，连体式）；后减震 3 个卧式风扇（2 减震+1 刹车），前部无风道

   - **⭐ 2026-10-09 升级（原"待补来源"已补上）**：魏建军那句"更大电池版本不会亏电"的**官媒一手出处已找到**——[证券日报 2026-06-08 魏建军专访](http://www.zqrb.cn/auto/qichedongtai/2026-06-08/A1780705006904.html)："长城汽车本次出征环塔拉力赛的坦克700……**同步研发了小电量 HEV、大电量 PHEV 两套混动动力方案**……**大电量版本在高强度越野场景中，电能储备、动力稳定性优势显著，而小电量版本则易出现亏电问题**。"

     → 关联档案：`offroad/docs/长城2027达喀尔-官方口径与摩洛哥站缺席核实.md` §五。
   - **物理框架（不依赖具体容量的独立支撑）**：容量 → 缓冲时间 → 重量代价已写入推演文档 **§7.7「HEV 的电池缓冲—重量权衡」**（口径声明块已同步升级）——以整车 0.4–1%（12–31kg）的重量代价换 +71% 缓冲时间，同时保留相对 PHEV（37.1kWh ≈247kg）的 ~200kg 减重；并明确 HEV 的对称代价（无长距离纯电、低速电驱扭矩弱）与"发动机直驱功率 ≥ 沙地需求才是第一功臣"的 SS9 反证。
   - **与 #261 的张力已被解释**：项目记 #261（1.75kWh）拿环塔 SS9 段全场最快，与"小电量易亏电"不矛盾——SS9 需求 128kW < V6 直驱 190kW，**缺口为负、电池不参与**；厂商说的是**全程高强度下的电能储备与稳定**。"单段最快"与"全程不亏电"是两个口径，**厂商口径与项目反推互相印证**。

## 六、归因修正（2026-08，用户指正）

**坦克 700 的胜势归因从"功率"改为"P2 架构"**：
- 事实基础：251 号账面功率在 T2 组**并不占优**（豹5 系 505kW、纵横 G700 等电驱对手账面都更高）；环塔 T2.E 组估计无严格功重比限制（待查证）
- 修正表述（已写入篇1 §一、§九）："混动的满态功率优势兑现成胜势" → "P2 架构的掉增量不掉根基（亏电后 3.0T 机械直驱兜底，后四段不掉速）"；"混动买功率" → "混动买直驱兜底"
- 车手主观感受（"动力源源不断"）是**持续输出**而非峰值爆发的体感，与账面功率不占优不矛盾
- 相关口径对比：卫士 OCTA 达喀尔认证重量 ≈2.5 吨（FIA 口径，不含燃油）vs 坦克 700 官方队 ≈3.0 吨（不含燃油）——500kg 结构性差距来自非承载大梁+PHEV 三电；达喀尔 T2 功重比 6.5kg/hp 下卫士限流至 ~400hp、坦克 700 若同规则限流至 ~460hp

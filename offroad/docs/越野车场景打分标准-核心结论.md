## 三、动力架构（9 种）

### SOC 三状态模型

| 状态 | 定义 | 纯油/P2 | 增程/DMO/DHT |
|------|------|------|------|
| **满功率** | SOC>20%，系统最大功率 | 发动机+电机 | P3/P4 全功率 |
| **中间态** | 亏电但发电/电驱未限功率 | =最弱态（P2 不存在此态） | P1 峰值发电→电驱 |
| **最弱态** | 亏电且限功率至额定 | 发动机直驱 | P1 持续发电→电驱 |

### 架构特性速览

**有机械根基（亏电不掉底）：**

| 架构 | 满态 | 弱态 | 核心优势 | 核心短板 |
|------|:---:|:---:|------|------|
| 纯油 V6 | ~190kW | ~190kW | 可预测，零跌落 | 低速无电机辅助 |
| P2 并联 V6 | ~300kW | ~190kW | 掉增量不掉根基 | 短冲刺自重劣势 |
| P2 并联 2.0T | ~250kW | ~150kW | 轻量化 P2 | 发动机降级 |
| HEV 浅充浅放 | ~200kW | ~190kW | 免电池死重，SS9 冠军 | 电机辅助量小 |

**无机械根基（亏电全线坍塌）：**

| 架构 | 满态 | 弱态 | 功率跌落比 | 核心短板 |
|------|:---:|:---:|:---:|------|
| 单档 DMO | ~300kW | ~100kW | 3:1 | 沙地=增程，P1 不够大 |
| 多档 DHT | ~300kW | ~60-80kW | 4:1 | P1 持续发电=生命线 |
| 功率分流+3DHT | ~635kW | ~100kW | 6:1 | 账面功率≠可用功率 |
| 增程式 | ~300kW | ~60kW | 5:1 | 二次转换损耗+重量螺旋 |
| T1+ 增程(奥迪) | ~288kW | ~220kW | 1.3:1 | 2100kg + 220kW 充电 + 散热自由 = 民用不可复制 |

### 核心定律

**越野车的弱态可持续功率，不由满态峰值功率决定，由"亏电后还有多少机械直驱功率"决定。**

**P2 并联上限不高（电机集成变速箱内做不大），但下限高（发动机直驱不掉底）。DMO/DHT/增程上限高（独立大电机满态爆发力惊人），但下限低（全线依赖 P1 发电，断崖掉速）。**

**速度反推实证（2026-08）**：环塔 SS9 纯沙漠，8 辆完赛电驱车（猛士 M817 + 纵横 G700/F700）速度 35-53km/h、平均约 45km/h（42-49 是车与车之间的分布区间，非同一辆车的满电→亏电过程），平均 45km/h 反推持续发电约 118kW（轮上约 100kW ÷ 0.85 两次转换），与 M817 官方"持续 110kW"同一量级——既验证该标称水分低，也证明 P1 持续发电就是电驱的速度天花板（对比 V6 直驱 190kW 在 55-58km/h 只需约 120kW 还有富余）。

## 四、悬架形式（4 种）

| 悬架 | 贴地性 | 强度 | 代表 | 核心特性 |
|------|:---:|:---:|------|------|
| 前后双叉臂独立 | ★★★★★ | ★★★ | 坦克 700 / 豹 5 / 捷途纵横 / 猛士 | 每个车轮独立跳动，高速搓板路/沙丘贴地最优 |
| 前双叉臂+后整体桥(含迪翁桥) | ★★★★ | ★★★★ | 坦克 300/火炮 V6/Hi4-Z | 后桥坚固抗冲击，贴地性略逊全独立 |
| 前后整体桥 | ★ | ★★★★★ | BJ212 | 极致强度但舒适性极差，600km 赛段=1200km 体感 |
| 前双叉臂+后多连杆 | ★★★ | ★★ | BJ60 等承载式硬派 | 民用 SUV 主流，行程和强度两头不占 |

> 勘误：豹 5 / 捷途纵横 G700 / 猛士 M817 均为**前后双叉臂**（多源参数确认），已从"前双叉臂+后多连杆"行移入"前后双叉臂独立"行；火炮 V6 量产为前双叉臂+后整体桥（非前后整体桥），前后整体桥代表为 BJ212。

**技术修正**：独立悬架可通过先进技术弥补行程短板（如卫士 6D 液压互联悬架），CAAMTB 原标准"悬架刚度/阻尼/横向稳定先进技术"三个指标在此生效。

### 卫士 OCTA 6D 液压互联悬架

全独立悬架通过技术补行程的行业标杆：

- **核心原理**：四轮减震器通过液压管路互联。交叉轴时压缩侧液压传递至对角侧→推拉伸侧车轮接地，模拟整体桥扭曲能力。高速过弯时液压自动锁定→零侧倾，取代机械防倾杆。
- **越野意义**：全独立悬架在攀爬/交叉轴的行程短板被大幅弥补，同时保留了独立悬架在高速戈壁的贴地优势。
- **对电驱指向**：多连杆悬架（豹 5/捷途/猛士）的行程弱势未来可通过类似系统补强，但目前无量产电驱车搭载——成本和电控兼容性是门槛。

## 五、四驱形式与限滑

| 限滑方式 | 延迟 | 持续能力 | 操作门槛 | 竞技可靠性 |
|------|:---:|:---:|:---:|:---:|
| **机械锁**（Mlock/LSD） | 零 | 无限（不发热） | 高（需预判） | ★★★★★ |
| **电子限滑**（制动/扭矩矢量） | 毫秒级 | 有限（发热衰减） | 低（自动介入） | ★★ |

- **卫士 OCTA 达喀尔版**：原厂电子后桥差速锁→赛用换成纯机械前/后限滑差速器。
- **电子限滑**：攀爬间歇不触发过热瓶颈，日常泥泞脱困小白友好。
- **电子限滑内部也要分层（iTAC 精确化）**：比亚迪 iTAC 复用电机旋变传感器做感知（精度约为传统轮速传感器 300 倍，>200Hz，提前约 50ms 预判打滑），执行端用降扭/负扭矩代替制动（不产热；且为**轴级**操作、拆不开左右轮，轮级降扭/负扭矩需易四方/易三方类每轮独立电机）——这部分**没有热衰减问题**；但同轴左右轮的轮间限滑仍需制动介入（同轴电机无独立轮间执行器），**持续脱困仍会发热**。所以"电子限滑发热"的准确适用范围是轮间制动限滑，不包括 iTAC 的轴间扭矩分配（方程豹称其为"能量中锁"——"三把锁"的第三把，无实物，10ms 内前后轴扭矩转移）。
- **辅助脱困功能三维度（CCO / 暴力模式 / iTAC）**：越野辅助功能按"接管对象"分三个独立维度，**可叠加不冲突**——**操作层**（长城 CCO 蠕行控制：系统代管油门+刹车，驾驶员只控方向盘，稳速通过坏路/爬山/沙漠；二代一键进入，R 挡可接入脱困倒车，4L+差速锁配合摇摆脱困）解决"会不会操作"（新手/陷车不会控油刹）；**标定层**（比亚迪暴力模式：**低速峰值扭矩 <2km/h + 滑移率≤3% + 轴间扭矩分配**的联合标定，⚠️**非限滑**）解决"车给不给力"（低速扭矩上限、低滑移蠕行）；**响应层**（iTAC：轴间扭矩转移/降扭/负扭矩，驱动域不产热）解决"打滑响应快不快"。三者互不替代：CCO 不改变车辆能力只接管操作，暴力模式不改变响应速度只解锁低速扭矩标定，iTAC 不涉及低速扭矩上限。打分体系中 CCO 对应"低速越野巡航"（越野配置及辅助功能指标），暴力模式/iTAC 对应限滑能力（动力传动及四驱系统指标）。_口径_：暴力模式滑移率≤3% 的表现易被误读为限滑，严格口径下限滑是 iTAC（驱动域降扭）与 ESP 制动（轮间）的维度（见 offroad/CONTEXT.md §CCO、perfect-e-offroad/CONTEXT.md §93）。
- **机械锁**：拉力赛持续脱困不发热，且不依赖电量——电四驱亏电后扭矩矢量能力同步崩溃。
- **百万坡**（平均 35-45°，最陡 50°）：大电机+全独立悬架+电子限滑占优势——攀爬是电驱甜点场景。

## 六、散热系统

**散热系统防护的问题不在散热器多，在改装方案。**

| 方案 | 代表 | 结果 |
|------|------|------|
| 官方队"达喀尔标准" | 坦克 700 官方队（保留量产多散热器+不切前杠+无后备水箱） | 至少 2 次事故：1 次退赛、1 次紧急维修勉强完赛 |
| 民间队"实战派" | 坦克 700 民间队（两侧副散热器切掉、主散热器上抬、增加后散热器） | 前散热器无重大安全事故 |
| 集中主散热器 | 卫士 OCTA 达喀尔（单一大尺寸+防沙过滤器） | 达喀尔冠军 |
| 电池冷却链路（电驱） | 豹 5 2025 环塔勘路车（底部风冷风道被细沙板结堵塞） | 勘路日电池过热锁速 → 正赛前退赛 |

- **民间坦克的思路近卫士 OCTA**：切掉两侧暴露的副散热器、主散热器上抬集中防护。民间队更激进——还增加了后散热器（巴哈风格），放弃达喀尔兼容限制。
- **民间改装的有效性边界**：民间队对散热对症下药（切副散热器、主散热器上抬）就无事故；但对官方硬件（典型如悬架）不了解、过度加强，其实无意义——官方硬件的强度与耐久性已经过工程验证，民间加码是冗余。民间能看见的是暴露面，看不见的是官方硬件的设计裕度（来源：B 站视频 BV1W1JG6fEVX，坦克民间车队改装分析）。
- **官方队的问题**：信任原始设计+极致减重，两侧副散热器保留且未加强防护，前杠未缩短→直接暴露在撞击风险中。
- **环塔电驱车额外热源**：发动机+P1+P3+P4+电池 = 五重热源叠加。
- **高海拔修正**：海拔每升 1000m，空气密度降 ~10%，撞风散热等比例下降。
- **豹 5 勘路退赛细节（2025 环塔，来源：虎扑帖附图，未经官方证实）**：5月22日勘路日 09:30 开始库木塔格赛段勘路，11:08 电池散热告警（BMS_ERR025，锁速 20km/h），14:20 技术组拆解确认底部风冷风道被细沙板结堵塞；5月24日提交退赛申请（编号 TT-2025-WD-101），5月25日正赛未出现在发车台。帖文"底部嵌入式风冷/放弃液冷减重约80kg"的措辞与量产豹 5 公开资料（刀片电池冷媒直冷）存在矛盾——最可能的机制是直冷链路放热端（风冷冷凝器）风道板结→制冷失效→电池过热，引用时保留"待证"标注。
- **散热失效是"硬死因"（非1即0）**：散热挂 = 退赛，不存在"部分完赛"——豹 5 在勘路阶段（正赛前）就出局。这区别于性能衰减类问题（亏电掉速是渐变，散热失效是二进制）。这正是"散热系统防护"在竞技强化指标中与防滚架并列 80 分（全场最高档）的原因。

## 七、场景 × 架构适配矩阵

| 场景 | 最优架构 | 核心逻辑 |
|------|------|------|
| 岩石/攀爬 | DMO/多档 DHT / P2 V6 | 大电机响应+电子限滑（攀爬间歇不发热），或 V6+机械锁 |
| 丛林/泥泞 | DMO/多档 DHT / P2 V6 | 大电机响应 vs 重量惩罚，各有优劣 |
| 日常通勤 | DMO/多档 DHT/增程 | 纯电舒适+零油耗 |
| 沙漠短冲刺 | DMO/多档 DHT（满态） | 满电爆发，环塔 SS4 电驱夺冠 |
| 沙漠长耐力 | **P2 V6（唯一解）** | 亏电不掉底，环塔 SS9 PHEV 55km/h vs 电驱 42-49km/h |
| 戈壁短冲刺 | DMO/多档 DHT（满态） | 同沙漠短冲刺逻辑 |
| 戈壁长耐力 | **P2 V6（唯一解）** | 高速持续+散热，环塔 SS3 坦克 700 平均 100km/h |
| 砂石竞速 | P2 V6 / 纯油 V6 | 综合可靠性，机械四驱不依赖电量 |
| 高原山路 | P2 V6 / 纯油 V6 | 涡轮高原不衰减+机械直驱 |

> **边界注脚（巴哈对照系）**：本矩阵结论坐标系 = 量产车（T2 组）+ 复合地形 + 可持续完赛。对照系：巴哈 Trophy Truck 五十余年保持**后驱 + 实心后轴 + spool（无差速器、左右半轴锁死）+ 1100hp 级 V8**，达喀尔 2010s 亦由两驱后置 buggy 统治（标致 3008 DKR 三连冠）——同一物理逻辑：高速沙漠巡航场景下四驱的抓地收益用不上，重量/传动损耗/故障点是纯负担，后驱 + 轻 + 简单可靠才是最优解。故：**低速脱困场景（攀爬/泥地/交叉轴）四驱权重不动（满分）；高速沙漠/戈壁巡航场景四驱权重可略降，为"轻 + 持续功率"腾出空间**（环塔内证：SS3 超长戈壁单赛段最快是火炮 V6 而非任何混动四驱）。只画边界，不改任何权重结论。

## 八、核心规律

1. **冲刺/间歇/低速/铺装 → 电驱主导（5 场景）**
2. **耐力/长距/持续 → P2 V6 唯我（2 场景）**
3. **中间地带 → 看距离和发动机排量（2 场景）**
4. **不存在一种架构统治所有场景。P2 上限不高下限高（适合拉力赛），电驱上限高下限低（适合日常）。**
5. **电子限滑在攀爬是优势（间歇+小白友好），在拉力赛是短板（持续发热+依赖电量）。**
6. **散热系统防护是赛事第一死因。官方改装方案（保留双副散热器+不切前杠）导致暴露风险，民间队切两侧、主散热器上抬集中防护后无事故。散热防护本质是改装方案问题，不是散热器数量问题。**

## 九、三状态权重参照

### 需要三状态加权的指标

"动力传动及四驱系统"下共 12 项指标，其中 **5 项**需要按 SOC 三状态拆分：

| 指标 | 三状态可变参数 |
|------|------|
| 车轮端单位质量牵引力 | 满态=(发动机+电机)扭矩；弱态=发动机扭矩 |
| 0-100km/h 加速时间 | 满态=电机辅助；弱态=纯发动机 |
| 动力响应性 | 驱动源不同→响应延迟不同 |
| 持续功率/保电能力 | 满态=系统峰值；中间态=P1峰值发电；弱态=P1持续发电 |
| 热管理(散热能力) | 满态=电驱热量小；弱态=P1持续发电+发动机=双热源 |

**不需要三状态拆分的 7 项**：变速箱、四驱系统、攀爬比（齿轮比不变）、前/后桥限滑、轮胎花纹、综合续航里程（油箱容量不变）。

### 各场景三状态权重矩阵

**核心原则**：里程越长 → 弱态权重越大。纯油和 P2 并联中间态=弱态（无独立中间态），两权重合并。

| 场景 | 满态占比 | 中间态占比 | 弱态占比 | 说明 |
|------|:---:|:---:|:---:|------|
| 岩石/攀爬 | 100% | 0% | 0% | 间歇性，直接取最强状态 |
| 丛林/泥泞 | 100% | 0% | 0% | 中低速间歇，满态为主 |
| 日常通勤 | 100% | 0% | 0% | 低强度，满态为主 |
| 沙漠短冲刺 | 90% | 10% | 0% | <100km 满态碾压 |
| 戈壁短冲刺 | 90% | 10% | 0% | 同沙漠短冲刺 |
| 戈壁长耐力 | 50% | 40% | 10% | 300-500km 高速巡航，中间态为主 |
| 砂石竞速 | 40% | 40% | 20% | 200-400km 中等负载综合 |
| 高原山路 | 30% | 30% | 40% | 200-500km 高海拔双杀 |
| 沙漠长耐力 | 20% | 30% | 50% | >350km 弱态主导 |

### 不同架构在三状态下的取值

| | 满态 | 中间态 | 弱态 |
|------|------|------|------|
| **纯油** | =发动机功率 | =发动机功率 | =发动机功率（三态相同） |
| **P2 并联** | 发动机+电机 | =弱态（P2无中间态） | 发动机直驱 |
| **DMO/DHT/功率分流/增程** | P3+P4 全功率 | P1 峰值发电→电驱 | P1 持续发电→电驱 |

**纯油和 P2 的三状态加权结果简化**：满态分 × W满 + 弱态分 × (W中+W弱)。DMO/DHT/增程需要三个状态独立计算。

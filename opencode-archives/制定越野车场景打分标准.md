**但后桥是迪翁桥——这是最大硬伤。** 

迪翁桥（De Dion）：差速器固定在车架，半轴连接两侧车轮。比整体桥操控好（降低非簧载质量），比独立悬架便宜，曾是高性能车的选择（法拉利、老款阿斯顿马丁）。但它的致命缺陷是：

- **左右轮不完全独立**——一侧车轮受到冲击，会通过半轴和连杆传递到对侧。
- **悬架行程受限**——行程不如双叉臂独立悬架，高速搓板路和连续沙丘中车轮贴地性差。
- **本质是非独立悬架的变种**——工程师用它是为了降低非簧载质量，而不是提升越野性能。

所以 Hi4-Z 在高速戈壁越野中后桥贴地性远不如坦克 700 的双叉臂独立悬架。**这套车更适合铺装路+轻度非铺装穿越，不是极限越野的解法。**

## DMO 为什么发动机和 P1 不能更大——根源是**重量螺旋陷阱**

**第一步：解耦电四驱的增重来源**

P2 并联（Hi4-T）的增加量 = P2 电机（集成在 9HAT 壳体内）+ 电池组 + 电控。9HAT vs 9AT 的增量可以通过坦克 400 纯油 vs 400 Hi4-T 的重量差推算——这个增量基本就是：P2 电机定子转子总成 + 电池组 + 逆变器。你的资料里应该没有坦克 400 的具体数字，但环塔总结提到：坦克 300 PHEV 约 2.6 吨，比同燃油版重约 200-250kg——这部分就是 P2+37kWh 电池+电控的总重量惩罚。

DMO 的解耦电四驱不是加一个电机，而是加**三个独立电机 + 三套电控 + 电池 + 复杂的耦合机构**。

| 部件 | P2 并联 | DMO |
|------|:---:|:---:|
| 驱动电机数量 | 1（P2，集成变速箱） | 2（P3 前桥 + P4 后桥，独立大功率） |
| 发电机 | 不需要（P2 无法同时发电和驱动） | 1（P1，独立） |
| 重量增量 | ~200-250kg | 远大于此 |

豹 5 已经 2.89 吨。DMO 要升级发动机（1.5T→2.0T）+ 加大 P1（150kW→更大）：发动机增 40-60kg，P1 增 20-40kg，更强的冷却系统增 20-30kg → 轻松破 3 吨。

**而且这还没完——发动机和 P1 加大后，电池也得加大（因为更大的发电功率需要更大的电池缓冲来吸收），电池是整车最重的单一部件。**

**第二步：3 吨对于一台"中型越野车"意味着什么**

2800mm 轴距，3 吨 = 在沙地里下陷更深，脱困需要更高的功率。但更高的功率需要更大的发动机和 P1 → 更重 → 陷得更深 → 需要更高功率……这就是**重量螺旋陷阱**。

P2 并联不存在这个陷阱——因为 P2 并联不需要"发电→电驱"的中间环节。V6 直驱车轮，190kW 就是 190kW，不管车重多少。**P2 的功率链路只有一条：油箱 → 发动机 → 传动轴 → 车轮。没有二次转换，没有重量放大。**

**第三步：所以 DMO 不是技术上不能做大——是物理上做大后收益递减到一个临界点**

假设比亚迪真给豹 5 塞一个 2.0T + 200kW P1——车重破 3.1 吨（和坦克 700 Hi4-T 同重）。但坦克 700 是 3000mm 轴距 + 3.0T V6 直驱，DMO 的 2.0T 还是只能发电。在沙漠耐力场景里，增程式逻辑下 200kW 发电 ≠ 200kW 直驱——二次转换还有 15-20% 损耗，到车轮只剩 160kW。对比 P2 V6 直驱 190kW 到车轮。差了 30kW 而且车更重。

**最终结论：DMO 架构的保电瓶颈不是调教问题，是物理**——纵置电驱的四驱灵活性是以重量为代价的。而加大发动机和 P1 只是在不收敛的螺旋上多加一圈。

## 悬架形式对比

五种越野悬架，按贴地性和强度的跷跷板排列：

---

### 1. 前后双叉臂独立（坦克 700）

- **最优点**：每个车轮独立跳动——高速搓板路和连续沙丘中贴地性无对手。环塔 SS3 戈壁 100km/h 平均速度就是证明。
- **结构**：上下两个 A 臂控制车轮运动，行程和倾角可独立调校。
- **缺点**：部件多、复杂——上下控制臂 + 球头 + 衬套多，环塔 SS5 魔鬼赛段暴露受损风险高。双叉臂的前轮转向节和半轴角度在极限落差时也更脆弱。
- **民用适配**：铺装路操控和舒适性都是最优。

---

### 2. 前双叉臂独立 + 后整体桥（坦克 300 / 火炮 V6）

- **后桥整体桥**：一根实心车桥通过钢板或连杆连接两个后轮。一侧轮被顶起，另一侧也跟着移动——压缩一侧通过车桥扭转传递到另一侧。
- **牺牲了独立跳动，换来了极致坚固。** 后桥只有一根桥壳 + 两根半轴 + 差速器，比独立悬架少了上百个铰接和衬套。环塔最复杂地形中没听说后整体桥断过。
- **高速搓板路差距**：后整体桥非簧载质量大（整根车桥+差速器），车轮跟不上高频颠簸——贴地性不如双叉臂独立，这会直接转化为速度损失。
- **坦克 300 环塔数据**：SS3 戈壁 94.3km/h（vs 坦克 700 的 100km/h），SS9 沙漠贴地性也逊于全独立的 700 系列——劣势清晰但不算致命。

---

### 3. 前后整体桥（火炮 V6）

- **极端强度、极端牺牲。** 两个实心车桥——没有独立车轮运动，一个轮受撞击，整根桥一起动。
- **优势：** 即使飞跳落地、底盘撞击岩石，断轴的可能性极低。Baja 赛车就是这个逻辑（后整体桥+超长行程钢板）。
- **劣势：** 非簧载质量极大——高速搓板路车轮几乎无法贴地，舒适性垫底。民用日常开就是折磨。600km 路程，车手体感 1200km。

---

### 4. 前双叉臂 + 后多连杆（豹 5 DMO／捷途纵横／猛士 M817）

- **多连杆**：4-5 根连杆定位车轮、弹簧和减震器分开安装。民用 SUV 的主流后悬——平价、省空间、舒适性好。
- **越野短板**：
  - 行程受限于连杆几何——远不如双叉臂的独立跷跷板效应，也不如整体桥的纯粹行程
  - 各连杆受力复杂，极端冲击下受力方向不可预计——强度不如整体桥
  - 连续沙丘中车轮贴地性差于双叉臂
- **环塔表现：** 没有全独立悬架的贴地优势，也没有整体桥的强度——两头不占。但民用 99% 场景感受不到这些。

---

### 5. 迪翁桥（坦克 Hi4-Z 后桥）

### 场景对限滑的需求分野

**岩石攀爬：电子限滑有优势**

攀爬是间歇性、短持续时间——电子系统来不及过热。电机毫秒级扭矩反向可以在轮胎打滑瞬间精确补偿，比机械锁的"要么锁死要么全开"更细腻。

而且**锁死后不可转向**对攀爬是硬伤——攀爬经常需要边攀边转向绕障碍物。电子限滑可以做到"滑转控制+同时转向"。

所以：百万坡让 DMO/DHT 的大电机 + 全独立悬架 + 电子限滑占尽优势。这是电驱架构的甜点场景，跟耐力越野完全相反。

---

**拉力赛：机械锁是唯一解**

卫士 OCTA 达喀尔版——原厂电子后桥差速锁→赛用换成**纯机械前后限滑差速器**。环塔坦克 Mlock 全赛程零故障。电四驱车型 SS5 出现过热故障。

**电子限滑在拉力赛的物理天花板：**

1. **制动式限滑**——制动片持续打滑制动，发热→热衰减→制动失效。在连续脱困工况（非间歇攀爬），几分钟后必然过热。
2. **扭矩矢量限滑**（电四驱）——限滑能力来自电机扭矩调节。但拉力赛长赛段下电池亏电→电机功率跌→扭矩矢量能力同步崩溃。**电四驱的限滑和动力是一根绳上的蚂蚱。**

机械锁没有这些问题——牙嵌式锁止，锁了就是锁了，不依赖任何外部能量输入。哪怕发动机只剩下 50kW（故障模式），锁止效果不变。

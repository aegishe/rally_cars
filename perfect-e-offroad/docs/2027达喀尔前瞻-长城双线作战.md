## 二、对本项目"完美电驱越野"架构的影响

### T2 组的启示

坦克 700 Hi4-T（P2 混动 V6）去达喀尔 T2——这是对 **"P2 并联是当前极限越野最优解"** 的最高级别背书。但同时也说明 P2 的上限天花板已经被触碰：V6+变速箱+P2 电机+3 吨车重的组合已达物理极限，再做不了更大电机。

本项目提出的**纯增程电四驱**如果进入 T2 级别赛事，理论上可以在相同重量下做到更高的持续功重比（68.8 vs 55.2 W/kg），但需要在真实赛事中验证：
- P1 190kW 持续在沙漠高温下的可靠性
- 三台 MGU 的软件协同标定稳定性
- 电四驱在复杂地形（SS5 魔鬼赛段级别）的容错率

### T1+ 组的启示

T1+ 原型组用 **4.0T V8 中置纯油**——这反过来说明：**在推重比至上的原型组别，电驱的重量惩罚仍然致命。** 奥迪 RS Q e-tron 的增程路线虽然赢了 2024 达喀尔，但那是靠赛方功率平衡规则和 2100kg 碳纤维车体才成立的。长城选择 V8 纯油进入 T1+，本质上选择了和丰田 GR DKR Hilux、达契亚 Sandrider 同一条路——内燃机推重比的物理上限高于现有电池/电机技术的上限。

本项目的纯增程电四驱定位于**民用**，不追求 T1+ 级别极致推重比。但如果未来电池能量密度有突破（比如固态电池 500Wh/kg 量产），纯增程的 T1+ 能力将被重新定义。

## 四、长城 4.0T V8 发动机详情（追记 2026-07-05）

基于发布会实车解析：

| | G40GF1（超跑/高性能） | 8Z40（越野/皮卡） |
|---|---|---|
| 冲程 | **短冲/方缸** | 长冲 |
| 红线 | **8000rpm** | 低转速 |
| 涡轮 | WGT 废气涡轮 | 同 |
| 喷油 | 双轨混喷 | 同 |
| 缸体 | **闭水道** | 同 |
| 油底壳 | **干式（三吸一泵）** | 可选干式 |
| 功率 | **≈450kW（600+hp）** | — |
| 平台 | GF 高性能家族 | 同平台 |

**关键信息**：
- 这台超跑用 P2+P4 混动 + 电四驱 + 前后扭矩矢量（9HATS 变速箱，可能摘除了液力变矩器）
- 短冲 V8 + 干式油底壳的组合在越野上完全可行——福特猛禽 R、RAM 等皮卡/越野车均大量采用短冲 V8，卫士 OCTA 达喀尔冠军也搭载了宝马短冲 V8（非路虎自研，但实战验证了短冲路线在极限越野中的可靠性）
- 演讲者提到"希望看到这台短冲 V8 装进 700 赛车发动机舱"——暗示 T1+ 参赛机可能不是 8Z40 而是 G40GF1
- 干式油底壳对越野的实质性提升：极端攀爬角度下不会断油（三个吸油点 + 储液罐冗余），环塔 700 赛车用的仍是湿式油底壳
- 对完美电驱越野的启示：增程器上干式油底壳可消除极限角度断油风险，是不增加传动系统复杂度的纯可靠性升级

# 全地形反馈适应系统对标

> 从 `perfect-e-offroad/CONTEXT.md` 的「全地形反馈适应系统（Terrain Response）对标」词条展开——路虎 Terrain Response 的官方机制、ATPC、熄火重置行为，以及本架构如何对标。术语定义仍见 `perfect-e-offroad/CONTEXT.md`。

## 路虎 Terrain Response 官方机制

**全地形反馈适应系统（Terrain Response）**：路虎 2004 年首发（发现3）、获发明专利的地形管理模式技术；第二代（Terrain Response 2）约 2014 年升级，新增自动模式。

机制分两层：

1. **预设标定**——路虎把研究各种路面得出的成熟驾驶习惯"写入程序、预先设定在车辆控制模式中"。驾驶员旋钮/按钮选择地形模式（普通、草地/砂砾/雪地、泥泞/车辙、沙地、岩石；卫士为"8+1"种），系统自动调节 **8 大子系统**：发动机管理、油门响应、动态稳定控制、电子制动力分配、陡坡缓降控制、电子牵引力控制、变速箱换挡设置、电子差速器。
2. **第二代自动模式（Auto）**——由传感器监测 **车轮打滑、转向角、横摆率、踏板输入** 四项，实时判断当前路况并自动选择/切换地形模式；驾驶员可手动锁定模式。

**熄火重置（关键边界）**：路虎官方规定，点火系统关闭 6 小时以上，选定的地形模式会自动取消，以降低在不当条件下误用模式的风险。即：地形模式不是常驻在线的，熄火即重置。

**全地形进程控制（ATPC）**：与 Terrain Response 协同的低速巡航——在 1.8–30 km/h 范围内设定并保持稳定车速，管理发动机输出与制动，用于复杂低摩擦地形（如沙地、泥泞下坡），驾驶员只管方向。

## 本架构对标关系

本架构（纯增程电四驱；篇5 后置对调方案沿用同一标定层）在**分层限滑的标定层**对标 Terrain Response 的机制：

- 对标的是"多地形模式预设 + 传感器路况识别自动切换"这套**标定哲学**，不是照搬路虎硬件。路虎地形识别靠车轮打滑/转向角/横摆率/踏板输入；本架构以电机旋变轴速、轮速、车身姿态等动力学信号为输入。
- 与分层限滑的接力分工：电子限滑（第一层）管瞬时打滑，机械 LSD（第二层）管持续脱困，标定层负责"按地形调前后扭矩分配、电机输出曲线、限滑阈值、回收强度"——见 CONTEXT「四驱与限滑」节。
- 差异声明：路虎 Terrain Response 是 2004 年起几十年的标定积累；本架构对标的是目标方向，成熟度差距客观存在（篇5 表述为"标定成熟度尽可能接近路虎"）。

## 纠正的早期错误说法

早期版本（已作废）曾写本架构优势为"传感器阵列、域控制器、全地形算法**永久在线**——停车过夜第二天着车瞬间已有地形预判"，并列举"摄像头、坡度、轮速、悬架行程、油门深度"作为感知输入。两处均不成立：

1. **"传感器永久在线"错误**——路虎官方机制恰恰相反：熄火 6 小时以上选定模式自动取消（熄火即重置）。车辆熄火后传感器断电，不存在"永久在线"；地形预判也不是"着车即恢复"，而是着车后由传感器重新实时判断。
2. **感知输入清单不准**——Terrain Response 2 Auto 的官方输入是**车轮打滑、转向角、横摆率、踏板输入**四项。旧清单里"轮速、油门深度"对应正确；"摄像头"是 ClearSight Ground View / 3D 全景的显示部件（给驾驶员看路，不参与地形识别）；"悬架行程"是被调节的**输出**而非感知输入；"坡度"非官方明示输入。

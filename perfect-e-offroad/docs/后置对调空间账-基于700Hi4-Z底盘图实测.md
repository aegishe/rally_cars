# 后置对调空间账（基于坦克 700 Hi4-Z 底盘图实测）

> 整理时间：2026-09-01。尺寸为用户在 700 Hi4-Z 底盘图上手工测量（比例尺：前后轴红线 = 轴距 3000mm）。用于验证篇5 后置对调方案的空间可行性。本记录只存实测数据与结论，不存计算细节。

## 实测数据（用户量，1px = 10mm）

| 量 | 换算 |
|---|---|
| 轴距 | 3000mm |
| 发动机→DHT 尾（动力链纵向长） | **1240mm** |
| 前轴→DHT 尾 | 730mm |
| 后轴→车架尾（后悬） | **1100mm** |
| P4 电机 | 600mm |
| 油箱前横梁（电池包后）→车架尾 | 2040mm |

## 布局（用户手工对调示意图，已随篇5 发布）

- P4（绿色）→ 前桥；发动机+DHT（棕色）→ 后桥；电池（银色）+ 油箱（黑色）保留中央。

## 大概结论

1. **对调空间上放得下**——电池+油箱都保得住，手工图布局成立；
2. **4 挡 DHT + 240kW 电机也放得下**——靠发动机整体后移吸收动力链长度（1370mm 级），代价不在座舱；
3. **离去角问题不大**（车架后部仍有空间）；
4. **核心矛盾收敛到配重**——动力单元压在车尾，45:55 配重目标难达成，这是后移后真正要解决的（重尾 vs 飞跳，参见篇5 §三.3）；
5. **图上未画的第一硬点**：后桥独立悬架/半轴与后置动力单元的干涉——空间放得下之后仍需处理；以及车尾散热（后置无撞风，篇5 §三.4 车顶进气缓解思路）。

# 如果我来造一台终极越野车——从纯增程到功率分流的电四驱纸上推演（v2 重构草稿）

> **声明先行：本文是纸上推演，不是实测，也不是量产预告。** 全部数字基于环塔实战数据、量产车拆装清单和达喀尔冠军车的工程验证，逐项标注口径。
> 本文是《参数与激情：从技术祛魅到需求自知》系列的应用延伸篇第一篇（完美电驱篇），紧接研究内核线的收官篇——把收官篇"上限与下限的兑换"反着用：既然上限和下限不可兼得，那就试试能不能把两端的代价都压到最小。
> 本版为八节重构第一稿：规则约束 → 整车物理架构 → 车轮与悬架 → 动力 → 传动 → 重量纪律 → 版本收敛 → 落地。

---

先从我自己的用车说起。城市为主，偶尔长途——坦克 500 Hi4-T 这样的 P2 车，本来处处合适：长途不怕没电，说走就走；城市里的油耗，也不是出不起。但 P2 的电机夹在变速箱里，功率做不大，开起来和大电机电四驱的车一比，总差一口气——爽，是要花架构钱的。谁不想既要、又要、还要呢？于是有了这篇推演：把长途的无焦虑、城市的低成本、电驱的爆发力，塞进同一台车。越野场景里，这道"既要又要还要"的题更难做——先看题面。

## 一、题面：越野车最需要的是什么

先说结论：**贴地、持续、不坏。** 不是马力。

环塔 13 个赛段是现成的证据：短距离冲刺，电驱夺冠，比的是峰值爆发；超长纯沙漠，HEV 反超，比的是弱态可持续功率；复合地形的魔鬼赛段，散热防护不够的先出局；戈壁长耐力，P2 机械四驱碾压——同一场比赛，四个冠军，各赢各的赛段。所以"越野车最需要什么"这个问题本身问得不完整：**必须先问"在什么规则下、跑什么场景"。**

规则分三档，每一档允许你动的要素不同：

- **T1+（原型组）**：钢管车架、37 英寸胎、2.3m 车宽、350mm 悬架行程、中置发动机——规则全开，厂商的答案是"轻量 + 大轴距 + 大轮距 + 大行程 + 马力"五件套（篇1 的收官结论）；
- **T2（量产组）**：必须在量产车骨架上做文章，环塔的答案是把量产车的每一克冗余都换成可靠性——改装清单全是加固和防护（坦克 700 环塔赛车）；
- **民用**：法规、耐久、舒适三座大山压着，绝大多数"赛用答案"直接出局。

于是推演的坐标系立起来了：**不是造一台 T1+（那不需要推演，照着达喀尔抄就行），也不是造一台 T2（那是在量产车上打补丁），而是造一台民用量产车，让它尽可能多地带上 T1+ 的物理。** 每一节都在这个约束下做取舍——哪些赛用物理能民用化，哪些不能，代价是什么。

## 二、整车物理架构（重要性最高）

收官篇的原话：规则约束下的整体架构，比动力架构更接近胜负手。动力架构是五个要素之一；整车物理架构决定剩下四个。这一节先立骨架，后面每一节的取舍都挂在这副骨架上。

**1. 车身：钢管车身 = 加强的承载式。**

先把一个常见的误解拆掉：越野车的车身不是"承载式 vs 非承载"的二选一。T1+ 的钢管车架本质上是**把承载式的"一体受力"做到极致**——空间管阵结构，车架即防滚架，受力逻辑和承载式一体车身完全相同，只是材料换成钢管、安全笼直接内置。它和大梁式非承载是两回事：没有大梁，车体下平面可以做得更干净，离地间隙的每一毫米都是可用行程。

民用承载式越野车（卫士 110 是承载式，轴距 3.022m）已经证明了这条路能走；真正的差距不在"有没有大梁"，在于**承载式车身的维修性和改装生态**——后整体桥+大梁的陆巡卖的就是这个生态（篇1 的原话：后硬桥为的是载荷、耐用和改装件生态）。对一台"终极越野车"来说，答案清晰：**承载式车身 + 前后独立悬架，用 6D 液压互联补行程短板**——达喀尔冠军卫士 OCTA 的底子就是它，T1+ 的钢管车架是它的赛用极限版。

**2. 通过角与轴距：先有通过角，再谈轴距。**

轴距的三十年答案，达喀尔已经交卷：2010 年代两驱后置 buggy 统治（标致 3008 DKR 三连冠、Mini JCW Buggy 接棒），转折在 T1+ 规则——厂商集体转投四驱长轴大车（丰田 GR DKR Hilux T1+ 约 3.14m、BRX Hunter 约 3.13m）。环塔 T2 组把这个答案复现了一遍：212 T01（2.62m 轴距）在 SS2 戈壁慢火炮（2.745m）26%，在最短的 SS11 冲刺段只慢 1 分钟——**轴距是"速度上限"问题，不是"能不能完赛"问题。**

但轴距不是白拉的：轴距越长，通过角越差，离地间隙越不值钱。所以顺序是**先定通过角目标，再定轴距**——本文推演车的通过角底线是"越野车场景打分标准"里的攀爬场景及格线，轴距因此压在 2850-3000mm 区间（§七三版本全部落在这个区间内）。

**3. 发动机布局：不考虑民用版本，中置/前中置更好。**

这条是本版新增的论证。论据链：

- **奥迪 RS Q e-tron 是增程架构，发动机不驱动任何车轮，只发电——理论上放哪里都行。工程师选了前中置**（front mid，维基口径；RC8 TFSI 约 200kW）。传动路径完全自由时，位置选择只剩重量平衡一个理由。这是"平衡优先于传动"最干净的一份证据；
- 丰田 GR DKR Hilux T1+ 中置后驱（Toyota Gazoo Racing 官方口径：mid-engine layout 自 2016 达喀尔沿用至今）、BRX Hunter 前中置四驱（Prodrive 口径）——**发动机贴重心是 T1+ 组的共性，驱动形式反而各家不同**；
- Trophy Truck 主流是前置 V8 + 后驱（维基口径），不是中置——不能当中置的证据，但它佐证另一件事：**后驱 + 后桥承载在高速越野完全可行**。

所以精确的表述不是"50:50 更好"（各厂没公开精确轴荷比），而是：**发动机贴近重心 → 前后轴荷均衡 + 俯仰转动惯量低 → 飞跳姿态可控、出弯响应快。** 对民用版本，中置发动机挤占乘员舱空间，得不偿失；但本文推演里的激进后置版（§七）假设"不考虑民用版本"的约束，发动机前中置、变速箱后置直驱后轮——布局有 T1+ 先例，代价写进诚实清单。

**4. 散热与防护：布置即防护，这是架构的一部分。**

环塔第一死因是散热，不是动力：坦克 700 两次水箱事故（SS5 飞跳撞击、SS9 前杠撞地）都是**物理损伤**，副散热器外露是暴露面问题；豹 5 勘路退赛是电池冷却风道沙尘板结；卫士 OCTA 的答案是单一大散热器 + 防沙过滤器 + 缩短前杠（集中防护）。**散热器放在哪、暴露面多大、撞了会不会死，是整车布置问题，不是散热器本身的问题。** 中置发动机布局在这件事上反而占便宜：车头没有发动机，散热模组可以后退到撞击区之外，前杠可以专心干"通过角"的活。

## 三、大车轮 + 大悬架行程

**轮胎就是贴地本身。** 悬架的一切努力，最终都是为了轮胎贴住地面——车轮离地的那零点几秒，马力、扭矩、锁全都作废。

- **车轮要大**：T1+ 规则把胎拉到 37 英寸不是拍脑袋——胎越大，同一个石块在轮胎眼里越小，接地面积越大，胎压可以放得越低。沙地冲坡的登顶名单里，改装桨叶胎 + 延长传动轴是标配（极氪 7X 登顶 Moreeb 那台车，视频配音说"基本原装"，画面里明明是桨叶胎 + 四轮突出车体——信源口径的坑，这里再踩一遍）；
- **行程要长**：高速冲坡时车轮在起伏沙面上高频跳动，行程决定车轮贴沙的时间。T1+ 的 350mm、巴哈的 1 米级行程，都是同一个物理——贴地时间就是速度上限。

悬架形式选型走铁三角（篇1s 的框架：规则 × 场景强度 × 故障容忍度）：**环塔验证过的分工是**——前后双叉臂独立贴地性最好（坦克 700 冠军车）、后整体桥强度最高但高速非铺装贴地是天花板（丰田跑达喀尔的 GR DKR Hilux T1+ 赛车用前后双叉臂独立悬架，量产陆巡的后硬桥是另一台车）、全独立补行程靠 6D 液压互联模拟整体桥扭曲。

主动悬架在这里要画一条边界：**民用量产的几条主动路线（800V 电液、48V 集成、直线电机、侧倾专项主动稳定杆）目前全部是厂商宣传口径，没有一条经过长距离越野验证**——800V 电液约 3kW 的持续功耗对着 30kWh 电池是纯负担，直线电机的大电流散热恰好撞上环塔第一死因，侧倾专项稳定杆的"公路连接/越野断开"二分法在 180km/h 戈壁高速段（既要行程又要侧倾支撑）是未验证的算法风险。所以本文的悬架答案与达喀尔冠军一致，两套：**民用默认 6D 液压互联（半主动、功耗可忽略），竞技方案金属弹簧 + 氮气减震 + 机械锁**——卫士 OCTA 冠军版把整套 6D 拆除换 Bilstein 被动位敏，就是在说：两周连续高强度冲击下，"全能"让位于"不死"。

## 四、动力架构：持续功率来源才是胜负手

先把四种现役架构摆上台（环塔体检报告，每缺一角都写在明处）：

| 架构 | 上限（满电爆发） | 下限（亏电持续） | 缺的那一角 |
|---|---|---|---|
| P2 并联（Hi4-T） | 中——电机夹在变速箱里做不大 | **高**——V6 直驱兜底 | 短冲刺爆发不足；P2 电机径向尺寸被变速箱壳体锁死 |
| DMO 单档（豹5） | **高**——独立大电机 | 低——P1 持续仅 91kW（汽车之家问答口径） | 沙漠长耐力断崖掉速 |
| 多档 DHT（Hi4-Z） | 高 | 中——有直驱档但换挡复杂 | 换挡不适合竞技（沙丘扭矩剧变，SS5 保电+散热退赛） |
| 纯增程（奥迪 RS Q e-tron） | 高 | **高**——220kW 持续发电 | 达喀尔冠军，但碳纤维车体+赛车电机不可复制 |

核心矛盾一句话：**"上限高"和"下限高"在现有民用架构里不可兼得。** 上限靠大电机（独立布置），下限靠大发动机（机械直驱或大功率发电），两样都重。

但环塔 SS9 把问题又挖深了一层。同一赛段的速度：700 HEV 58.9、700 PHEV 55.4、电驱 42-49 km/h——**纯沙漠考的不是标称功率，是弱态可持续功率。** 8 辆完赛电驱车平均约 45km/h，对应轮上约 100kW、持续发电约 118kW，与官方标称的持续发电量级一致（猛士 M817 官方口径 110kW）——**P1 持续发电功率就是电驱越野的速度天花板。** 电驱车"亏电全线坍塌"的病根不是电池不够大，是 P1 太小。

于是路线收敛到纯增程电四驱（标准版与长轴版的主线）：发动机不通过任何机械路径连接车轮，只驱动 P1 发电机；前桥 P3、后桥 P4 独立电机，无传动轴；拓扑与达喀尔冠军奥迪 RS Q e-tron 一致——**路线本身已经被最高级别赛事验证过**。砍掉变速箱/分动箱/传动轴约 160kg，省下的重量全押在 P1 上：从民用级的 60-91kW 跃升到 190kW 持续。

代价提前说（标准版/长轴版）：**没有机械直驱路径，P1 或高压系统一旦故障，全车瘫痪。** 不必拿 P2 来衬托——P2 的高压系统同样失效后，纯发动机模式背着三百公斤电池死重，能挪，但挪不出竞争力，两者的差别只是退赛姿势。纯增程真正的短板是"没有冗余路径"这件事本身——§七的激进后置版，正是用一条机械直驱路径把这个洞补上。

## 五、四驱与限滑/差速锁

环塔的答案很直白：**机械四驱零故障完赛，电四驱过热罚时。** 但这不意味着电四驱没戏——它输的是"持续"，赢的是"响应"。两台驱动电机分别控制前后桥，扭矩分配由软件完成（虚拟中央差速器），响应是毫秒级；机械四驱的传动轴+分动箱+锁，响应是物理级（零延迟），持续能力无限（不发热）。

差速锁谱系排一下：Mlock（机械牙嵌，硬连接，强度最高）→ 电控多片离合器（可调，会过热）→ 机械 LSD（扭矩偏置，零延迟不发热，但"响应慢"是相对电子而言）→ 电子制动限滑（毫秒级，持续高负荷过热）。

本文的分层限滑是**接力，不是二选一**：

| 层级 | 手段 | 响应 | 持续能力 | 死穴 |
|---|---|---|---|---|
| 第一层 | 电子制动限滑（对标 iTAC 响应速度） | 毫秒级 | 差（发热衰减） | 持续高负荷过热 |
| 第二层 | 机械 LSD（对标卫士达喀尔赛车） | 零延迟 | **无限**（不发热） | 相对电子"慢" |

电子限滑管瞬时打滑（攀爬、泥泞、小白友好），全地形控制器监测制动盘温度/介入频率，超热阈值就关电子通道，机械 LSD 靠扭矩偏置特性无缝接管。环塔验证过两个结论——电子限滑在攀爬是优势（间歇工况+响应快）、在拉力赛是短板（持续发热）——这套分层把两个结论同时用上。P1 持续供电，SOC 归零时全地形控制器和限滑决策不掉线。

## 六、重量与能量纪律

先拆一个坊间直觉。常有人说电四驱比机械四驱轻——砍掉变速箱、分动箱、传动轴，省出一大截。实测不是这样：**坦克 500 Hi4-T（机械四驱）vs 坦克 500 Hi4-Z（解耦电四驱），同车体，两套传动系统的总重差只有 4kg。**

```
机械四驱：9HAT 混动变速箱 + 分动箱 + Mlock + 前后传动轴 + P2 电机
电四驱：  3 档 DHT + P2 双角色电机 + P4 后桥电机 + 控制器
两者重量几乎完全相等。
```

砍掉传动链省下的 160kg 级重量，刚好被大电机和控制器吃回去。**"电四驱轻"是个伪命题——重量优势只能靠电机本身的功率密度挖出来。**

同车体的 4kg 之外，跨车型再对照一组：豹5（DMO 电四驱）对坦克 400 Hi4-T（P2 机械四驱）——两车内饰豪华程度接近。整备质量豹5 2890kg（官方参数口径，普通悬架版；云辇版 2920kg 带液压悬架，不参与对比）、坦克 400 2770kg，豹5 重 120kg；而豹5 的电池还小 5.3kWh（31.8 vs 37.1kWh），LFP 刀片反而更重 38kg——**排除电池后，豹5 的非电池重量仍高出约 80kg**。电四驱在整车层面更重，重的不是电池，是结构冗余（DMO 的 CTB 结构电池 + 独立大梁双重堆重，分析推断口径）。

还有一处不对称值得点明：坦克 400/500/700 系是环塔 T2 组实战验证过的车体，量产原厂强度直接达标；豹5 在环塔是勘路阶段退赛（电池冷却风道沙尘板结，篇1 口径）。推演基准选坦克系而不选豹5，就是这个原因——重量纪律要的是被赛事压榨过的下限，不是没被压榨过的初代平台上限（这也是边界声明里"排除初代平台基准"那句话的由来）。

于是有了整场推演最关键的一个参照物：

**奥迪 MGU05：35kg（含逆变器），250kW 峰值，200kW 持续，跑完 14 天达喀尔。**

它是 Formula E 赛车电机技术的产物。按民用电机密度（豹5 实测反推），三台电机要 235kg；按 MGU05 对标，**三台合计 102kg——省下 133kg**。这是本文全部推演里权重最高的单项假设，也是最贵的一个（见 §八 诚实清单）。

能量纪律同样有一刀：电池该配多大，不是看续航，是看峰值与持续的缺口——**30kWh 是"不浪费"的尺度**：

$$(356\text{kW 系统峰值} - 190\text{kW P1 持续}) \div 6\text{C} \approx 29.4\text{kWh}$$

30kWh 刚好补上"电机想爆发、发电机供不上"的缺口。豹5 配 31.8kWh 是因为它的 P1 只有 91kW，必须靠大电池缓冲；本架构 P1 190kW 已覆盖沙漠巡航需求，大电池只会增重。**电池容量是 P1 功率的补丁：P1 越大，电池可以越小，车越轻。** 重量纪律贯穿全篇——车身、电机、电池、悬架的每一项选择，最后都写进整备质量，再写进功重比。

## 七、版本收敛：标准版 → 长轴版 → 激进后置版

把方案在三个量产基准车上逐项拆装（全部从量产车基准推，不用初代平台，避免"从虚高往下降"的乐观偏差）：

| | 标准版 | 长轴版 | 激进后置版 |
|---|---|---|---|
| 基准车 | 坦克 400 Hi4-T | 坦克 500 Hi4-T→拉伸 | 坦克 700 Hi4-Z（前后轴对调） |
| 轴距 | ≈2850mm | ≈3000mm | ≈3000mm |
| 拓扑 | 纯增程 P1+P3+P4 | 纯增程 P1+P3+P4 | 发动机直驱后轮 + 发电供前桥 |
| 电池 | 30kWh | 30kWh | 15kWh |
| 整备 | **≈2635kg** | ≈2795kg | **≈2692kg** |
| 满电功重比 | 135 | 127 | **163**（全场最高） |
| 亏电功重比 | 61.5 | 58.0 | **63.1** |
| 跌落比 | 2.20:1 | 2.20:1 | **1.59:1** |

**标准版**（2635kg）的对照是坦克 400（2770kg，满电 108 / 亏电 55.2）：满电 +25%、亏电 +12%，同尺寸双杀。

**长轴版**（2795kg）撞上了物理墙：满电 127 微胜坦克 700（124），亏电 58.0 大幅落后（71.1，-18%）。**坦克 700 的 V6 直驱 260kW 是增程 P1 190kW 追不上的鸿沟**——要追上需要 P1 ≈285kW 持续，即 ≈300kW 机械功率的增程器，那等于把 V6 改成增程机；而 V6 直接驱动比"先发电再电驱"更高效。**元结论："3 吨以上，P2 最优"不受电机减重影响——瓶颈是发电功率，不是电机重量。** 电机再轻，也发不出 V6 直驱的持续功率。

**激进后置版**（2692kg）是本版修订的重点。原稿的拓扑是"发动机+变速箱后置直驱后轮"——重量全压后桥，俯仰惯量难看。按 §二 的布局论证修订：**发动机前中置（贴重心），行星齿轮 4 档动力分流变速箱后置直驱后轮，前桥只用一颗低功率 P4 辅助，砍掉 P1 发电机、电池缩到 15kWh。** 严格说它已经偏离纯增程——后桥那套行星齿轮变速箱让发动机既能机械直驱后轮、又能带动电机发电供前桥，这是一台**功率分流架构**（THS 路线的纵置后驱化），不是串联增程。它的意义恰恰在这里：纯增程没有机械冗余路径的短板被发动机直驱补上，代价是重新背起变速箱的复杂度。结果：满电 163 全场最高，亏电 63.1 不掉，跌落比 1.59:1 逼近 P2 的 1.48:1——**把 P2 的下限和电驱的上限塞进同一个车体，只是前后轴对调了角色。** 行星齿轮+4 档的档位设置是 C 攀爬/1 沙锅/2 戈壁/3 冲刺、无超速档——卫士达喀尔已证明拉力赛不需要超速档。

三个版本的共同底线：**亏电不掉速的架构逻辑 + 不超过 2.8 吨的重量纪律。**

## 八、落地清单：成本、技术来源、民用化

按项目纪律，把推演里所有可能塌的假设列全：

1. **P1 190kW 持续电机无量产民用产品**——这是商业问题不是物理问题（奥迪 220kW 已验证），但定制或赛车技术下放的成本未知，整场推演的成本可行性悬在这一个点上；
2. **MGU05 下放民用是假设**——35kg/250kW 的电机密度来自赛车工程，民用降本后的重量和成本没有对标物；
3. **30kWh 6C 持续放电的电芯寿命**未验证——6C 是快充级倍率，长时间持续放电的循环寿命是行业难题；
4. **无机械直驱路径**（标准版/长轴版）——P1/高压系统单点失效即全车瘫痪，没有任何机械冗余路径；激进后置版以发动机直驱补上这条冗余，代价是重新背起行星齿轮变速箱的复杂度与工程风险；
5. **激进后置版新增：发动机前中置 + 变速箱后置的传动包络**——发动机到后桥的传动轴/纵置一体化布置是工程挑战（T1+ 的中置车是钢管车架随便摆，量产承载式里没有现成先例），此项列为本文最不确定的单项；
6. **三台 MGU 的软件协同标定复杂度陡增**——扭矩分配、动能回收、虚拟差速器的响应延迟都依赖软件成熟度，这是环塔电驱车高额罚时的同一片雷区；
7. **五重热源**（发动机+P1+P3+P4+电池）的散热器面积与布置是工程挑战——环塔第一死因就是散热；
8. 6D 液压互联在纯增程架构下的高压总线兼容性（液压泵长时连续工作的过热）待确认。

**这篇推演的价值不在"这样造一定成"，在于把"完美越野车"的约束显式化：上限由电机功率密度定价，下限由发电功率（纯增程版）或直驱功率（激进版）定价，两者之间的兑换率就是车重。** 现有架构的每一种"缺一角"，都是在这个兑换里做出了取舍；本文只是把取舍摆到台面上——至于这台车会不会被造出来，等 P1 190kW 量产的那一天。

## 边界声明

1. 全文为纸上推演，标题与开头已明示"非实测"；所有整备质量、功重比、跌落比均为工程估算（数据源：环塔 2026 实战 + 量产车拆装清单 + 奥迪/卫士达喀尔工程验证）；
2. 重量推算从量产车基准逐项拆装（坦克 400/500/700），**排除初代平台基准（豹5/猛士 M817）**，避免乐观偏差；单项误差 ±20kg 级，横向对比结论对单项误差不敏感；
3. MGU05 下放、190kW P1、6C 寿命、行星齿轮 4 档、发动机前中置 + 变速箱后置的传动包络均为假设，未经验证；
4. "3 吨以上 P2 最优"的结论基于当前电机/电池技术水平的持续功重比对比，固态电池等高能量密度技术突破后需重新评估。

## 结论清单

◆ 越野车最需要的是贴地、持续、不坏——但"最需要什么"必须先问"在什么规则下跑什么场景"（T1+ 全开 / T2 量产骨架 / 民用三档）。

◆ 整车物理架构优先于动力架构：承载式车身是正确路线，通过角先于轴距，发动机贴重心（中置/前中置）比贴驱动轴重要，散热布置就是架构的一部分。

◆ 悬架答案与达喀尔冠军一致：民用 6D 液压互联，竞技金属弹簧 + 位敏阻尼 + 机械锁；主动悬架民用量产路线全部厂商口径、未经长距离越野验证，不进候选。

◆ 电驱越野的速度天花板是 P1 持续发电功率：纯增程把省下的 160kg 传动链重量全押在 P1 上（190kW），30kWh 电池只是峰值缺口的补丁。

◆ 电四驱不轻：与机械四驱只差 4kg，重量优势只能靠电机功率密度挖出来——MGU05（三台 102kg）是整场推演权重最高的单项假设。

◆ 三版本收敛：标准版双杀坦克 400；长轴版撞上 V6 直驱的物理墙（"3 吨以上 P2 最优"不受电机减重影响）；激进后置版发动机前中置 + 变速箱后置，跌落比 1.59:1 逼近 P2，代价是传动包络与复杂度。

◆ 全文推演，非实测：P1 190kW、MGU05 下放、6C 寿命、中置-后置传动包络，四件事悬着，落地清单见 §八。

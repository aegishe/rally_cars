# 中国V缸复兴：转速派与扭矩派的四条路线

> 主题：浩思动力 W30 V6 / 长城 4.0T V8 / 长城 GF 超跑 V8 / 莲花 Esprit V8  
> 信息时间：2026 年 4–7 月公开报道  
> 分析时间：2026 年 8 月  
> 信源分级：A=官方发布 · B=主流汽车媒体 · C=自媒体/论坛传闻  
> 关联体系：track（赛道）/ 动力架构术语（P2 并联、多挡混联 DHT）

---

## 零、一句话总结

1. **传闻属实且有官方背书**：莲花（吉利旗下）确认从 2027 年起用吉利-雷诺合资公司"浩思动力"的 V6/V8 混动系统替换现有燃油动力；长城的超跑 V8 也已随 GF 高性能架构官宣。准确说法不是"吉利在莲花平台推 V6 超跑"，而是"莲花用浩思动力的发动机推自己的跑车/超跑"。
2. **V6 配跑车、V8 配超跑**：浩思 W30 V6 装 2027 款 Emira；真正对标"混动超跑"的是 986hp+ 的 V8 Esprit（2028）与长城 GF 超跑（GT3 版 2027、民用插混版 1200hp+）。
3. **两条路线同台分野**：浩思走"高转轻量"转速派（8000rpm、160kg），长城走"低转大扭"扭矩派（770–800Nm、92 号油、十字曲轴）——2026 北京车展同台，中国动力总成第一次在同一届车展展示两条完全分化的 V 缸技术路线。
4. **"方缸体"是误传**：长城超跑 V8 已确认用十字曲轴（低转取向），与"方缸=缸径行程相等=高转机"的车圈定义恰好相反，无任何信源支持"方缸"说法。

## 二、浩思动力 W30 V6：转速派代表

**浩思动力（Horse Powertrain）**：吉利旗下极光湾科技 + 雷诺旗下 Horse 科技合并而成。股权口径：吉利 45% / 雷诺 45% / 沙特阿美 10%（阿美 2024 年入股后的口径；早期报道为吉利雷诺各 50%）。定位独立动力总成供应商，给吉利、雷诺系及莲花供货。

**W30 发动机参数**（[A: 新华社](https://app.xinhuanet.com/news/article.html?articleId) / [B: Car and Driver](https://www.caranddriver.com/news/a71296938/lotus-emira-new-hybrid-v6-confirmed/)）：

| 参数 | 数值 |
|------|------|
| 排量/结构 | 3.0L V6 涡轮增压（未来可扩展 V8） |
| 功率 | 350–400 kW（476–544 hp） |
| 扭矩 | 600–700 N·m |
| 红线转速 | **8000 rpm** |
| 整机净重 | **160 kg**，比行业最轻 V6 再轻约 10 kg |
| 混动搭档 | 4LDHT 四速混动专用变速箱，内部集成双电机，整套系统（含发动机）199 kg |

技术取向：**小排量 + 高转速 + 轻量化**换功率，支持轻混/全混/插混三用。架构上是**多挡混联 DHT**（非 P2 并联）。

## 三、长城 4.0T V8：扭矩派代表

**参数**（[C→B: 车家号](https://chejiahao.m.autohome.com.cn/info/25521888) 等多源一致）：

| 参数 | 数值 |
|------|------|
| 排量/结构 | 4.0L 90° V8 双涡轮（hot-V 布局，涡轮置于 V 型夹角中央） |
| 功率 | 404 kW（549 hp） |
| 扭矩 | **770–800 N·m** |
| 热效率 | **38–38.5%** |
| 油耗/油品 | 百公里 13 L，**92 号汽油** |
| 曲轴 | **十字曲轴**（非平面曲轴） |
| 其他 | 智能闭缸（中低负荷 V8→V4） |
| 混动 | 预留 P2 电机位，配 Hi4-T 可做 P2 并联插混（综合 450kW 为传闻口径） |

坦克 700 V8 版插混口径：纯油 549hp/770Nm，混动综合 782hp/1000Nm。落地车型：坦克 800 等高端越野旗舰。技术取向：**大排量 + 低转高扭 + 喝粗粮**，工具属性，面向中东/俄罗斯/澳洲等全球越野市场。

## 四、错位对比：V6 vs V8（排量差 33%、缸数差 2）

| 维度 | 浩思 W30 V6 | 长城 4.0T V8 |
|------|------------|-------------|
| 最大功率 | 350–400 kW（544 hp 上限） | 404 kW（549 hp） |
| 峰值扭矩 | 600–700 N·m | 770–800 N·m |
| 红线转速 | 8000 rpm | 未公布（4.0T 惯例 ~6500 rpm） |
| **升功率** | **117–133 kW/L** | **101 kW/L** |
| 热效率 | 未公布 | 38–38.5% |
| 燃油标号 | 未公布（跑车取向） | 92 号 |
| 整机重量 | 160 kg | 未公布（同级 4.0T 参考 210–240 kg） |
| 混动架构 | 4LDHT 四挡双电机（混联 DHT） | Hi4-T P2（并联） |
| 落地 | Emira（2027）→ 扩缸 V8 给 Esprit（2028） | 坦克 800 等 / GF 超跑（另一调校） |

**四个观察**：

1. **升功率差 15–30%**：W30 用 3.0L 榨出与 4.0L V8 几乎持平的功率，靠高转速换功率；长城靠排量堆低转扭矩墙。转速机器 vs 扭矩机器。
2. **热效率与油品**：长城把 V8 做成"工具"（38%+ 热效率、13L、92 号），浩思把 V6 做成"图腾"（热效率油品均未公布，面对欧洲排放法规与 95/98 市场）。
3. **混动路线分野落在项目架构体系两端**：长城 P2 并联（油主电辅）= 项目已验证的极限越野最优解；浩思多挡混联 DHT = 跑车场景让发动机锁高效点。印证项目结论"不存在一种架构统治所有场景"。
4. **战略底色**：合资借船（浩思，雷诺渠道解决欧洲本土化与充电焦虑）vs 全自研（长城，泛内燃机战略 + 品牌向上）。

## 五、长城 GF 超跑与"方缸"传闻辨析

### 5.1 传闻主体属实

GF 高性能架构（[A: 经济网](http://m.ce.cn/bwzg/202604/t20260428_2935837.shtml) / [C: 搜狐](https://www.sohu.com/a/1016966069_100202083)）：三大核心为赛道级 4.0T V8、中置四驱、全碳纤维单体壳，由前迈凯伦工程师领衔，对标法拉利。

| 节点 | 内容 |
|------|------|
| 2027 | GT3 赛车先行（限功率 600hp、整车 1.3 吨以下，"明年上海见"） |
| 2027–2028 | 民用超跑版：V8 双涡轮插混，**系统综合功率 1200hp+**，前轴 P4 电机 + 9HAT，中置四驱 |
| 传闻参数 | 1000hp 级、2.5s 破百、350km/h（[C: 搜狐](https://www.sohu.com/a/918674612_134157)） |

**2026-08 视频实测补充（四个 B站视频字幕，Whisper 转写）**：

- **技术总监官方确认布局**（[B站采访](https://www.bilibili.com/video/BV1zxRuBZEbF/)，英文，Adam Thompson，前迈凯伦 GT 首席工程师）：**前轴单 P4（镁合金）+ 中置 4.0L V8 + 后 9 速 + P2**，碳纤维单体壳；原话"平台不打算做纯电——纯电技术目前不足以支撑这类产品的性能"。
- **项目负责人透露**（[B站采访](https://www.bilibili.com/video/BV1N7o2B2EVP/)）：车重目标 **1.8-1.9 吨**、电池十几度、布局"人-电池-发动机"纵置、尺寸对标法拉利 488/保时捷 992、三种驱动模式（纯油后驱/运动后驱/运动四驱）、减重抠到螺丝掏空。
- **展品被质疑"烟雾弹"**（[B站分析](https://www.bilibili.com/video/BV1DQRPBvEij/)）：大飞轮把发动机架高、无结构件固定点、传动轴转 3 个 90°、碳纤维轴占扩散器宽度——据此判定展品是模型，真机待发布。

### 5.2 两个 V8？"方缸"与"十字曲轴"的调和（2026-08 更新）

- 车圈术语：**"方缸"= 缸径 = 行程**（如 86×86）；短冲 + **平面曲轴**才是高转 V8 范式（法拉利、AMG M178、兰博基尼万转 V8）。十字曲轴 = 低转扭矩厚 + 低沉声浪，转速响应与极限转速天然弱于平面曲轴。
- **车展现场解读**（[B站](https://www.bilibili.com/video/BV1qF9CBDE2h)）明确：超跑 V8 代号 **G40 GF1**，与越野版 **8Z40**"同属一个家族、同一个平台"，但"改了燃烧室"——越野版长冲低转，超跑版"可能方缸、偏短冲、8000rpm"。
- **新浪爆料**（[C: 新浪超跑项目爆料](https://www.sina.cn/news/detail/5292308582629618.html)）称超跑量产版用十字曲轴（低转）——与车展解读的"方缸 8000rpm"矛盾。
- **推断（待真机）**：矛盾的可能解是**长城有两个 V8（一平台两机）**——越野版 8Z40（十字曲轴、长冲、92 号油、770-800Nm）+ 超跑版 G40 GF1（方缸/短冲、8000rpm、干式油底壳）；新浪爆料或把越野版十字曲轴误套到超跑版，或爆料过时。此前"一机两吃"的判断相应改为"一平台两机"。
- 叠加展品被质疑烟雾弹（§八），超跑版 V8 的曲轴/转速取向仍待真机确认。

## 六、莲花 Esprit V8 超跑

- 2028 年发布，**986hp+ 混动 V8**（[B: Driving](https://driving.ca/auto-news/entertainment/2028-lotus-esprit-hybrid-supercar-emira-horse-v6-teaser)），V8 由浩思 W30 扩缸而来。

- 与长城 GF 超跑构成"国产 V8 超跑双雄"，一条高转轻量路线、一条低转大扭 + 电机补偿路线。

## 七、格局：四条路线一览

| | W30 V6（浩思） | 长城 4.0T V8（越野版） | 长城 GF 超跑 V8 | 浩思 V8（Esprit） |
|---|---|---|---|---|
| 缸数 | V6 | V8 | V8 | V8 |
| 取向 | 高转轻量（8000rpm） | 低转大扭（92 号油） | 高转 8000rpm（待真机） | 高转轻量（继承 W30） |
| 曲轴 | 未公布 | 十字曲轴 | 待真机（可能平面） | 未公布 |
| 混动 | 4LDHT 混联 | Hi4-T P2（预留） | 插混，系统 1200hp+ | 混动，986hp+ |
| 落地 | Emira（2027） | 坦克 800 等 | GT3（2027）/ 民用（2027–28） | Esprit（2028） |
| 底牌 | 吉利-雷诺合资 + 欧洲渠道 | 全自研 + 泛内燃机战略 | 全自研 + 碳壳 + GT3 背书 | 雷诺本土化 + 莲花品牌 |

结论：**不是内卷，是分工**——转速派与扭矩派各占赛道与越野两个极端，恰好复刻本项目场景体系里"赛道 vs 越野"的架构分野。

## 八、存疑与待观察清单

1. ⚠️ **Emira 是否真上混动**：[emiraforum 消息](https://www.emiraforum.com/threads/upcoming-emira-horse-w30-transmission-information.8359/)（2026-07-02）称"Emira 不会获得新混动总成，未来只有 M139"，与 5 月官方口径冲突——混动版可能推迟或另设车款。
2. 台湾媒体曾报 Emira 或采用"以电机为主的'路遥'增程混动单元"（[C: tcar](https://www.tcar.tv/article.php?infoid)），与 DHT 混动说法不一致。
3. 长城超跑民用版 1200hp/2.5s/350km/h 均为传闻口径，待官方确认；GF 超跑 V8 与坦克 800 V8 是否为同一基础机的不同调校，官方未明确。
4. 长城 V8 缸径/行程、整机重量未公布；浩思 V8 具体参数未公布。
5. 节奏风险：W30 样机 2026-07 才下线，2027 装车偏紧；Esprit、GF 民用版都是 2027 年后的变量。
6. 2026-08 车展现场解读称超跑 V8"方缸短冲 8000rpm"，与"十字曲轴低转"矛盾；叠加展品被质疑为烟雾弹，超跑 V8 的曲轴/转速取向待真机确认。
7. 技术总监采访确认前轴为**单 P4**（非此前 smzdm 传闻的"双 P4 封装一体"），官方口径以单 P4 为准。
